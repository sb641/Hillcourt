# client/ — Godot-клиент. ФАЗА 0: ЗАМОРОЖЕНО.

В фазе 0 сюда **не пишет никто**. Сначала должны быть готовы симуляция, данные и тесты.
Симуляция не знает спрайтов, рендер не считает ренту (И-5).

Когда клиент откроют (отдельным ADR), он:

- читает снимки состояния из `sim/`, но не считает экономику сам;
- не импортируется в `sim/`;
- не требуется для запуска тестов и headless-прогона.

Проверка: в `client/` нет файлов, кроме этого README; `bash sim/run_tests.sh` проходит без Godot.
