# System Verdict v0: по слоям

## Назначение

Комплексная оценка v0 по обязательным слоям. Формат каждого слоя: состояние / дыра / цена дыры
для игрока / не чинить сейчас, если не блокирует v0.

## Правила

### 1. Материя и калории

- Состояние: дельта 0 на 36 и 60 мес; `Ledger` различает `external_in/transfer/process`;
  рты взрослый 1.0, ребёнок 0.7; едят flour→meat→grain.
- Дыра: 33 дворовых-месяца голода, все на тяглых (villein 27), при растущем амбаре лорда.
  Соль — тупиковый товар (`edible: false`, нет входа ни в один рецепт).
- Цена для игрока: его «богатый» манор держится на голодных, которые не могут уйти. Соль не
  покупается и не продаётся — она не нужна.
- Не чинить сейчас: менять числа yield/пайка — нет. Сначала правда пути соли (слой 7).

### 2. Труд и календарь барщины

- Состояние: взрослый 20 дней/мес, раб 20 всегда, сезонная барщина (виллан 8/12/12/8, коттер
  4/4/12/4), помочи cap 3/год. `phase_manor` снимает руки до `phase_labor` — проверено тестами.
- Дыра: `phase_obligations` только записывает долг; это верно. Но нет эффекта от `ease_week_work`
  в прогоне — действие не вызывается.
- Цена для игрока: барщина как рычаг существует, но не дергается. Календарь — правда.
- Не чинить: календарь.

### 3. Право и оси статуса

- Состояние: три оси совпадают с онтологией (`personal_status`, `land_relation`,
  `obligation_bundle`); 8 пресетов; `can_leave` у tied = false.
- Дыра: `holder` у соляной деревни = `secure_holding`, но дворы вне книги и никогда не платят
  вверх — «равные» держатели существуют в вакууме.
- Цена для игрока: верх баронии ему неподвластен: соляная деревня не обязана ничем.
- Не чинить сейчас: да, отложить до появления пути/обоза (слой 7).

### 4. Книга манора и нарезка земли

- Состояние: `Manor` — книга; корень один, вложенный тен `depth ≤ 1`; амбар обязателен;
  пожалование атомарно; `revoke` сливает сток.
- Дыра: два параллельных механизма нарезки (`grant_tenure` и `grant_tenement`), у первого нет
  записи в лог/книгу и другой `rent_share`.
- Цена для игрока: неоднозначность «я уже отдал или нет»; книга может разойтись с `World.rights`.
- Не чинить сейчас: нет — это часть рычагов (шаг B).

### 5. Пожалование тена: имитация ярлыком

- Состояние: механика есть и протестирована (21 тест), амбар/домен/`household.manor_id`
  работают.
- Дыра: вверх не идёт ни материя, ни дни, ни люди. `upward_bundle` читается только в `state_hash`.
  `mustered` — bool; тела нет.
- Цена для игрока: он платит землёй и руками, а получает флаг. Единственный «вассал» v0
  бесполезен.
- Не чинить сейчас: нет — это ядро фантазии (шаг D), но после правды пути (A) и книги (B).

### 6. Известия и всеведение

- Состояние: `build_player_view/knowledge` только из доставленных `Report`; задержка, шум,
  искажение, `stale > 2 мес` — покрыто тестами. Всеведения нет.
- Дыра: субъектов `household/manor/thegn` нет; действия игрока не порождают Report; отчёт обоза
  смотрит в пустой сток; `offices.yml` не читается.
- Цена для игрока: почта врёт не потому, что искажает, а потому что смотрит не туда; решений
  игрока в летописи нет.
- Не чинить сейчас: частично — исправить источник обоза дёшево (шаг C), субъекты — позже.

### 7. Путь, воз, дальняя соль

- Состояние: `Pack` есть, но создаётся только тестами; `send_party` несёт пустой cargo;
  `phase_travel` разрешает дошедшие посылки.
- Дыра: `caravan_visit` не исполняется; соль из деревни никуда не едет; 0 transfer соли;
  замок за 60 мес не получил ни грамма.
- Цена для игрока: столп «путь и дальняя соль имеют цену» — ложь: цены нет, потому что пути нет.
- Не чинить сейчас: нет — это пункт A1 бэклога.

### 8. Hazard как тело (волки), не ивент

- Состояние: `wolves` крадут зерно у совпавших по клетке (0.5×intensity/мес); риск пути
  уносит человека; потеря отряда даёт `silence`, а не пересказ.
- Дыра: набор `Hazard` статичен; `wolves_den`/`band_camp` не исполняются; `bog` без месячного
  эффекта; волки не размножаются и не гибнут.
- Цена для игрока: опасность — декорация; она не растёт от ухода людей и не отвечает на решения.
- Не чинить сейчас: нет — шаг E, но ниже A/B.

### 9. Рычаги игрока в логе

- Состояние: шесть действий пишут `player_actions`; `runner` их не вызывает; лог их не печатает.
- Дыра: `grant_tenure/send_party/add_obligation` не логируются; `revoke_tenure` и пр. не сделаны.
- Цена для игрока: в headless он зритель. Проверить решение нельзя.
- Не чинить сейчас: нет — шаг B.

### 10. Масштаб и LOD

- Состояние: 63 клетки, 14 дворов, месяц — тик; дневного обхода всех `Person` нет; pathfinding
  нет. Скрытого RimWorld на всю карту нет.
- Дыра: соляная деревня считается поштучно, хотя заявлена как дальняя; но это допустимо.
- Цена для игрока: нет.
- Не чинить: нет.

### 11. Обещано в docs, но нет в runner

- `spawn_rules` pack/hazard/ruin — мертвы; `caravan` и `sheriff` — только Report.
- Соляная деревня как агрегат-LOD — нет.
- Руина как объект/событие — нет.
- `Muster` как появление вооружённого человека — нет.
- `revoke_tenure`, `set_rent_share`, `send_pack`, `send_messenger`, `patrol` — заявлены, нет.
- `docs/08_manor.md:67-71` отстал от кода (перевод по-манорски уже сделан).
- `docs/03_ontology.md` обещает Report на каждое действие — не выполняется.

в `gd_intake.md`/`role_gaps.md`; ни один пункт не требует нового класса `Knight`.
