# Лист приёмки v0 (канон, чтобы не верить памяти)

## Назначение

Единая точка приёмки фазы v0: чем именно принимается мир, какое число считается окном,
что считается провалом. Документ для смены, которая не помнит прошлую ночь: приёмка —
это воспроизводимый runner-лог, а не «looks better». Все числа ниже сняты 21.09.2026
на ревизии, где `bash sim/run_tests.sh` даёт `Ran 217 tests ... OK`, и сверены с ADR
0011–0016. Окно — допустимый диапазон; при изменении экономики окно меняет новый ADR,
а не подгоняется прогоном.

## Правила

### 1. Обязательные команды приёмки (ровно эти)

```bash
bash sim/run_tests.sh
PYTHONPATH=sim/src python3 -m hillcourt.runner --scenario design/scenarios/v0_hill_and_salt.yml --months 36 --seed 1729
PYTHONPATH=sim/src python3 -m hillcourt.runner --scenario design/scenarios/v0_two_settlements.yml --months 60 --seed 42
PYTHONPATH=sim/src python3 -m hillcourt.runner --scenario design/scenarios/v0_shire.yml --months 60 --seed 1729
```

**Окна и провал:**

- `bash sim/run_tests.sh` — окно: **217+ тестов, `OK`** (на 21.09.2026 — 217; больше — ок,
  меньше 217 или есть `FAILED` — провал).
- `v0_hill_and_salt.yml --months 36 --seed 1729` — окно: **замковая соль 15.6, дельта
  `-0.000000`**. Провал: соль `4.0`, дельта ≠ 0 (это базовая ложь A1 из 0011).
- `v0_two_settlements.yml --months 60 --seed 42` — окно: **дельта `-0.000000`, соль 15.6,
  живых дворов 17 (окно 14–18, baseline 0011: 16), голодных месяцев 272 (> 0)**. Провал:
  дельта ≠ 0, соль `0.0`, живых вне 14–18 или голодных месяцев `0`.
- `v0_shire.yml --months 60 --seed 1729` — окно: **дельта `±0.000000`, соль 15.6, живых
  дворов 26, голодных месяцев 535 (> 0)**. Провал: дельта ≠ 0, соль `0.0`, живых вне
  24–28 или голодных месяцев `0`.

**Последовательный запуск обязателен.** Команды выполнять по одной; не запускать runner
параллельно с `sim/run_tests.sh`. Параллельный прогон меняет число известий, голодных
месяцев и `state_hash` (процессное G6 в `design/review/backlog_v0.md`). Приёмка на
незамороженном воркспейсе недействительна; приёмка без runner-лога — не приёмка.

### 2. Replay: один seed — один мир

```bash
PYTHONPATH=sim/src python3 -c "from pathlib import Path; from hillcourt.runner import run; S=Path('design/scenarios/v0_two_settlements.yml'); a=run(S,60,seed=42); b=run(S,60,seed=42); print(a.state_hash==b.state_hash, a.state_hash)"
```

Окно: **`True`** и одинаковый `state_hash` у обоих прогонов. Провал: `False` или разные
хеши. На 21.09.2026 хеш (seed 42, префикс из ADR 0015/0016) — **`affee56b`**;
`v0_shire` seed 1729 — **`abf199ef`**. Хэши — снимок ревизии, а не окно: смена
`state_hash` при правке экономики оформляется ADR, а не подгонкой.

### 3. Ledger-проверки соли (тот же мир, seed 42, 60 мес)

```bash
PYTHONPATH=sim/src python3 - <<'PY'
from pathlib import Path
from hillcourt.scenario import load_scenario
from hillcourt.engine.tick import run_month
w = load_scenario(Path("design/scenarios/v0_two_settlements.yml"), seed=42)
for _ in range(60):
    run_month(w)
salt = [e for e in w.ledger.entries if e.good == "salt"]
load = [e for e in salt if e.reason == "caravan_load"]
unload = [e for e in salt if e.reason == "caravan_unload"]
ext_in = [e for e in salt if e.kind == "external_in"]
teleport = [e for e in salt if e.kind == "transfer"
            and e.src_id.startswith("household:") and e.dst_id == "settlement:hill_court"]
print("load", len(load), "unload", len(unload),
      "unloaded_total", round(sum(e.amount for e in unload), 3))
print("external_in", len(ext_in), "teleport household->castle", len(teleport))
PY
```

Окно: **caravan_load > 0, caravan_unload > 0, сумма выгрузки в замок > 0**, `external_in = 0`,
`teleport household→castle = 0`. На 21.09.2026: `load 7`, `unload 5`,
`unloaded_total 11.6`, `external_in 0`, `teleport 0`. Провал: `external_in` соли > 0
(материя из ничего), телепорт household→castle > 0 (соль без `Pack`), или выгрузок нет.
Обязательная цепочка: соль идёт `household:hh_salt_* → pack:caravan_* → settlement:hill_court`,
а не напрямую.

### 5. Запрещено

- «looks better» / «смотреть глазами» как критерий; приёмка без runner-лога и без числа.
- Подгонять окно под текущий прогон вместо нового ADR.
- Расширять мир до 50 дворов / 4 тэнов: backlog v0, раздел G («50/4 — не сейчас»).
- Запускать приёмку на незамороженном воркспейсе или параллельно с тестами.
- Выдумывать числа: окна — из 0011–0016, число тестов — из `bash sim/run_tests.sh`.

### 7. Качественные окна интеграции закона (2026-09-21, ADR 0028)

После вшивания сдач (тайл, усадьба, путь, вода, тягло, служба тэна) приёмка проверяет
**причинности**, а не подгонку одного числа:

- **Соль всё ещё едет по суше.** `caravan_load`/`caravan_unload` соли > 0, `external_in 0`,
  телепорт household→castle 0 (раздел 3). Живой обоз строит маршрут `find_path` профилем
  `caravan` (ADR 0029), поэтому дорога/брод/мост дешевят и его; река без переправы
  непроходима, телепорта нет.
- **Даль не стала всеведением.** `Report eye_from_hill` — только о клетках радиуса 1 от зала
  корня; `salt_village`/`ash_village` видны лишь через `caravan`/`silence`
  (`test_seat_place`, `test_far_village_report`).
- **Кап клетки не обойдён.** Шестой двор не садится (`settle_rejected reason=tile_full`),
  полный сосед не выбирается миграцией (`test_tile_view`).
- **Книга сходится после отзыва.** `revoke_thegn` возвращает землю/дворы/амбар в корень,
  дельта материи 0, бывший держатель жив `free_landless` (`test_manor_entity`,
  `test_thegn_service`).
- **Тэн без комплекта не явился.** `mustered`/`service_met` ложны без `war_kit ≥ 1`
  (`test_thegn_service`).
- **Стройка не берёт материю из воздуха.** `roadwork_material` — перевод `log` → `sink:waste`;
  без рук прогресса и завершения нет (`test_roadworks`).
- **Скот жив и честен (ADR 0030).** Шир стартует с тремя парами (волы `hh_11`-виллан,
  ослы `hh_14`, кони `hh_09` + сено), конь — только у свободного; за 12 мес по товарам пар
  0 проводок `starved` (естественный падёж допускается), `gather_hay` в леджере, дельта 0
  (`test_shire_draft_start`, `test_bloom_and_hay`); крица производится рецептом, но
  к действию не подключена. Провал: `tied`-двор с бонусом коня, скот из `external_in`,
  пара, взятая голодом, или голодных месяцев 0.
- **Сено первое.** `phase_hay` идёт до поля (`test_hay_before_field`); поле худеет честно,
  дельта 0. Провал: косьба после поля или за счёт несуществующего труда.
- **Лемех официален, но не подключён.** `smith_iron_share` в каталоге с балансом 1.8=1.8
  (`test_smith_iron_share_official`); `iron_bloom` — только `smith_kit`. Провал: лемех из
  крицы или `iron_share` без рецепта.
- **Люди — не материя (ADR 0031, принято в смене 7).** Роды идут, дельта 0, новорождённые
  не едят общий жребий (характер из хеша); смертность по возрасту, расцвет в иммунитете
  для грантов. Провал: Ledger в демографии, труд новорождённым, роды в голод.
- **Покупка, а не появление (ADR 0033/0035).** Бревно/скот/свиньи — только `transfer` на
  своей клетке по фикс-ценам; пара неделима; серебро из ничего не создаётся. Провал:
  `external_in` скота/брёвен, межклеточный торг без ADR.
- **Резерв косьбы и кузня (E1/E2).** Тягловый двор держит до 50% рук на сено (не голодая);
  дорогое — только сытому при входах. Провал: косьба без труда, кузня впроголодь.
- **Должность без депеш (ADR 0034).** Поле `produces_report` упразднено везде кроме истории;
  вести — обоз, молчание, события. Провал: поле в каталоге/загрузчике/тесте.

Провал: соль < 4.0 или дельта ≠ 0; `eye_from_hill` о дальней клетке; шестой двор на клетке (кап 5);
материя после `revoke` не сошлась; `mustered` без комплекта; tag клетки без рук.
