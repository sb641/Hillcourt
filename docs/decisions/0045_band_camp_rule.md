# 0045. Шаг 1 pipeline ватаги: контракт `band_camp` (Economist)

Дата: 2026-09-23. Роль: Economist. Шаг 1 pipeline (решение цикла 13, образец —
ADR 0042). Старые ADR не правятся. Зона строго своя: каталог + тест каталога;
фаза — следующим заходом Implementer (+Info: весть).

## Контекст

Замер стендом (без кода): гейт `terrain: marsh` + `min_households: 3` не
выполняется нигде (дворов на топях 0 во всех трёх мирах); принудительная ватага
(int 1.0) — влияние 0 везде (кража бьёт только по своей клетке, соль идёт мимо
угроз). Вывод: входит без пересмотра окон. Кража ватаги — `hazards.yml:band`
(2.0 против 0.5 у волков) — правилом не меняется.

## Решение

Контракт (только данные): `mode: spawn` — условное появление СТОЯЧЕЙ угрозы
(в отличие от волчьего topup: ватаге некого дотягивать — её нигде нет);
`min_households: 3`, `base_prob: 0.02`; рождение `intensity_init` 1.0 /
`population_init` 3.0 (размер шайки — под гейт); потолки `intensity_cap` 1.0 /
`population_cap` 6.0 (бесконечных ватаг нет; рост сверх рождения — будущим
решением); бросок через `rng_stream: hazard`; новая сущность — только с вестью
(`report_required: true`, рождение за Info при фазе, иначе И-3). Исполнителя
для ватаги в тике нет: 12 мес шира — ни ватаг, ни дрейфа чужих угроз.

## Альтернативы

- Режим topup как у волков — отклонено: дотягивать некого (ватаг в мире нет).
- Потолки выше/без — отклонено: бесконечные ватаги.
- Вшить фазу этим ADR — отклонено: чужая зона без exemption.
- Тронуть кражу 2.0 — запрещено задачей (без изменений).

## Последствия

Влияния нет — канон цикла 13 обязан стоять бит-в-бит, включая хеши
(hill 12/15.6/31, two 14/15.6/341, shire 25/15.6/539, дельта 0). Гейты two ≥ 14 /
shire 24–28 держатся тривиально; 13 = перебазировка. Сюит +3 теста. Фаза +
весть — следующие шаги по этому контракту.

## Что запрещено следующим агентам

1. Рожать ватагу без вести и без `rng.hazard`.
2. Сеять ватагу вне топи / ниже гейта этим правилом.
3. Поднимать потолки и кражу без нового ADR с окнами.
4. Дописывать фазу в каталог.
