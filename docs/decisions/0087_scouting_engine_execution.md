# 0087. Исполнение: физическая разведка `Pack` (Implementer)

Дата: 2026-09-24. Роль: Implementer. Исполнена движковая часть ADR 0074 в
`ontology.py`, `engine/`, `world.py` и `sim/tests/`; канал Info не менялся.

## Назначение

Дать разведке физическое место наблюдения, честного свидетеля и детерминированный
результат, не расширяя знание игрока до доставленной вести.

## Правила

1. `Pack.purpose ∈ {party,scout}`, обычное значение по умолчанию — `party`.
   `Pack.profile_id ∈ {hunters,forester,party}`, по умолчанию — `party`; `tower`
   отклоняется. Наблюдатель отдельно не хранится, `observer_id` события равен
   `Pack.id`.
2. Наблюдает только активная разведка с живыми участниками в одной гекс-клетке.
   Гексы маршрута и клетка нахождения дают факт без броска. Кольцо 1 использует
   `rng.world`; кольцо 2 даёт только слух `дым/след/костёр` с `confidence=0.5`.
   Клетки вне маршрута и колец 1–2 молчат.
3. Базовый шанс кольца 1: `hunters=0.85`, `forester=0.75`, `party=0.55`. Лес и
   топь дают сильный покров `×1.0`, поле и луг — слабый `×0.5`, прочие террейны
   `×0.75`. Активная `Hazard` даёт множитель
   `1-min(0.75, 0.5*max_active_intensity)`.
4. Результат — событие месяца `kind="scout_observe"` с `tile_id`, `fact/rumor`,
   `confidence`, `date`, `observer_id`, `source="scout"`. `engine/events.py`
   объединяет его с событиями журнала; `news.scouting` превращает событие в
   доставленный `Report`. `known_tiles` движком не меняется.
5. `state_hash` включает `purpose` и `profile_id`; одинаковый seed даёт одинаковые
   события и хеш, разные значения полей — разные хеши. Материя не меняется.

## Контекст

ADR 0074 утвердил минимальные поля `Pack` и физические правила, а Info уже
реализовал канал `scout_observe → Report`. Нужно было соединить их без новой
сущности наблюдателя и без обхода И-3.

## Решение

Использовать `Pack` как единственного наблюдателя, месячную фазу пути как момент
наблюдения, `rng.world` как физический поток и `news.scouting` как единственного
владельца доставленного знания.

## Альтернативы

- Хранить текущую клетку в `Pack` отклонено: ADR 0074 запрещает лишнее поле, а
  участники уже хранят местонахождение.
- Обновлять `known_tiles` из движка отклонено как нарушение И-3.
- Статическая башня отклонена до отдельного ADR.

## Последствия

Обычные Pack остаются без разведки и не читают новый RNG. Одна дозорная партия
даёт события только для маршрута и двух колец; хеш мира теперь различает цель и
профиль посылки. Каноны §1 не сдвинулись.

## Что запрещено следующим агентам

1. Расширять знание движком без доставленного `Report`.
2. Наблюдать дальше кольца 2 вне маршрута или без активной разведки.
3. Трогать `rng.news` из физического наблюдения.
4. Вводить `tower`, `Scout` или отдельное поле наблюдателя без нового ADR.
