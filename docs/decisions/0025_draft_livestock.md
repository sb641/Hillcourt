# 0025. Скот и тягло: вол, осёл, конь (Economist)

## Контекст

В каталоге был один общий `horse` без рецептов, приплода и роли: благо-мёртвый
груз (корм 1.0 в `needs.yml`, применения нет). Пахота зависела только от
инструмента (`tool_yield_factor`: нет 1.0 < плуг 1.05 < лемех 1.15), воз — только
от телеги. Задача зоны: три животных (вол — пахота, осёл — воз, конь — воз
быстрее/верх), пол в стоке, редкий приплод, корм и падёж, без магии, без
фермы-кликера, без появления из меню. Чужие зоны: норма службы тэна и
`mustered` (военное правило), реки/вид тайла/радиус усадьбы/yield мира, каталоги
Legal, боевой движок кавалерии, энциклопедия пород.

Ролевой разбор (глаза наблюдателей):
- Виллан без вола: пашет трудом, 20 трудодней за партию `harvest_grain`
  (factor 1.0); барщина уже сняла руки до `phase_labor`, взять зерно неоткуда.
- Виллан с волом в пахоту: та же партия стоит 14 трудодней (×0.7) — тот же
  труд даёт ~1.43× партий. Каждая партия ест стоячую материю и сходится:
  выход труда, не зерно с неба.
- Хозяин воза: телега остаётся главной (×1.5/×0.6, дни ×1.5 без); осёл сверху
  ×1.2 ёмкости, конь ×1.3 и дни ×0.75. Пеший — база; вол воза не знает.
- Держатель, которому предлагают коня: коня держат свободные; tied-двор
  с коня не начинает. Рабочий конь нормой не считается.

## Решение

1. **Каталог.** Общий `horse` удалён (пол различается в самом стоке, вторую
   «лошадь_2» не заводить): `ox_m/ox_f` (Вол/Корова), `donkey_m/donkey_f`
   (Осёл/Ослица), `horse_m/horse_f` (Жеребец/Кобыла), молодняк
   `ox_calf/donkey_foal/horse_foal`. Все — `livestock`/`barn`, несъедобны.
   Роль помечена здесь и в коде: вол — пахота, осёл — воз, конь — work|ride;
   боевое применение коня не считается (флажок владельцу военных правил).
2. **Корм** (`needs.yml`): сено; вол 1.2/1.0, осёл 0.7, конь 1.0, молодняк
   0.4/0.3/0.4, свинья 0.5 как была. Едят дворы (тик), амбары и склады
   (`livestock_month`); без корма — падёж от голода как у свиней.
3. **Приплод** (рецепты `breed_*`, `transform`): пара взрослых одного вида
   в одном стоке + 4 сена → 1 молодняк + 3 потерь (4 = 1 + 3). Родители —
   условие, не вход: кобыла не исчезает. Шанс 0.08/мес на пару (~1 в год).
4. **Взросление** (рецепты `mature_*`, `transform`): молодняк + 2 сена →
   взрослый + 2 потерь; пол — жребием (~0.2/мес на голову).
5. **Пахота** (`economy/labor.py`): тягло множит ТРУД партии `harvest_grain`
   (вол 0.7, конь 0.9 — хуже вола, одно правило; осёл/молодняк 1.0).
   Инструмент и его тесты не тронуты: без тягла плуг живёт за полный труд.
6. **Воз** (`economy/caravan.py`): тягло origin поверх телеги (осёл ×1.2,
   конь ×1.3 ёмкости и ×0.75 дней ceil); сигнатуры обратно совместимы
   (`draft="none"` по умолчанию). Тягло остаётся на месте, в воз не грузится.
7. **Падёж** сытого стада: 0.005/мес взрослые, 0.01 молодняк (целые головы
   в `sink:waste`, `died`); свиней не трогает (иначе поплыл бы канон).
8. **Тик**: `livestock_month` в конце `phase_consume` (труд не списывает —
   биология пассивна). Без скота — ни проводки, ни броска RNG: канон бит-в-бит.
9. **Legal-предложка** (каталоги Legal не тронуты): `can_hold_horse` —
   только `free`; ни один tied-двор сценариев с коня не начинает (зонд).

## Альтернативы

- **Приплод рецептом труда через `tend_animals`** — отклонено: кликер вместо
  биологии; труд тронул бы канон голода.
- **Родители входом (кобыла расходуется)** — отклонено: кобыла исчезала бы;
  условие-пара + сено держит массу и смысл.
- **Множитель урожая вместо труда** — отклонено: магическое +зерно и конфликт
  с `test_grant_tool` (порядок none < плуг < лемех обязан держаться).
- **Молодняк массой 0.5 со взрослением без сена** — отклонено: дробные головы
  и рост из ничего; целые головы + сено за рост.
- **Новый `horse` рядом со старым** — отклонено: дубль `horse`/`horse_2`;
  старый удалён, пол — в id стока.

## Последствия

- `sim/tests/test_draft_livestock.py` — 17 зондов (каталог, пахота, воз,
  приплод, корм, держание, служба); `bash sim/run_tests.sh` — 346 OK.
- Канон не двинулся: сценарии не менялись (скота в старте нет), без скота
  фаза пуста и RNG не тратит.
- `docs/09_economy.md` §5/§9/§10 — правила тягла; этот ADR — место правды.

## Что запрещено следующим агентам

1. Заводить `horse_2`/общий `horse` рядом с половыми id.
2. Поднимать `BREED_PROB` выше 0.1 и списывать труд на приплод/взросление.
3. Считать тягло комплектом (`war_kit`/`fief_kits` — только железо) и боевой
   движок кавалерии в этой зоне.
4. Давать tied-дворам коня в старте без ADR и согласия Legal.
5. Кормить/плодить скот через `external_in`: только `transfer`/`emit` рецепта.
6. Трогать реки/вид тайла/радиус усадьбы/yield (чужие зоны) под предлогом тягла.
7. Убирать `cap_per_tile`, лаг `labor_days > 0` у рецептов скота (требует тест
   каталога), правило «один плохой сезон — не повод» у службы тэна.

## Проверка

```bash
bash sim/run_tests.sh
PYTHONPATH=sim/src python3 -m unittest sim.tests.test_draft_livestock -v
```

Критерий: все тесты зелёные; зонд пахоты показывает вол > конь > без;
зонд приплода — кобыла цела + молодняк; дельта материи 0 везде.
