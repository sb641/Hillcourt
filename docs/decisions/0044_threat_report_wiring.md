# 0044. Проводка вести топ-апа в живой тик (Implementer, одна строка)

Дата: 2026-09-23. Роль: Implementer. Добивка связки 0042/0043: весть Info
(`news/threats.py::report_pending_topups`) сдана, но в тике не вызывалась —
`phase_inform` растил волков молча, гейт `report_required` в проде не ехал.
Зона Info не тронута (ни текстов, ни канала, ни задержек).

## Контекст

Контракт метки (0043): `wolves_den_topup` + `wolves_den_topup_<id>` в
`world.stats`. Читатель Info (`report_pending_topups`): метка со штампом
текущего месяца → `Report` (`messenger`, задержка 0, шум только `rng.news`);
прошлые штампы игнорит, дубли давит проверкой
`source + subject_id + event_date`. В тике вызова не было — чинил здесь.

## Решение

`engine/tick.py::phase_inform` вызывает `report_pending_topups(world)` после
сводки и глаза (импорт `news.threats`; чтения мира вестью напрямую как было,
так и нет — весть строит Info). Пин связки —
`TestThreatWiring` в `sim/tests/test_wolves_den_phase.py`: живой месяц
с топ-апом → ровно одна весть (`messenger`, клетка стаи) в `PlayerView`;
месяц без топ-апа → тишина; повторный `phase_inform` → без дублей.

## Альтернативы

- Звать читателя из `phase_hazard` — отклонено: вести рождаются в `inform`
  (фаза 14), не в середине тика.
- Отдельный поток под шум угрозы — отклонено: шум вести — штатно `rng.news`;
  четыре потока `RngStreams` не расширяются ради одной строки.
