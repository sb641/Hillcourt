# 0080. Кандидат миграции — только пригодный гекс (Orchestrator)

Дата: 2026-09-24. Роль: Orchestrator (владелец решения). Исполнитель: Implementer
(`engine/`). Старые ADR не правятся. Номер выдан после того, как ADR 0078 занял 0078, а
ADR 0079 — 0079.

## Назначение

Двор, который уходит с надела, должен встать **туда, где можно жить**: не в воду, не в
руину без жилья, не в режим без dwellings. Иначе «миграция» — это телепорт в никуда, и
окна канонов меряют не тот процесс.

## Контекст

После ADR 0071 кандидатами миграции стали шесть соседей, но отбор опирался в основном на
кап (`TILE_MAX_HOUSEHOLDS`), а не на пригодность места: вода и руины формально подходили.
Systems (проект последствий гексов, цикл 57) предложил разделить «свободно» и «пригодно»:
кандидат — только гекс, который вообще пригоден для поселения. Глобальный кап плотности
заводить не будем: дворы расползаются локально, по одному гексу на месяц, и на 100×100 это
не мгновенное уплотнение, а расползание волной.

## Правила

1. **Кандидат миграции = сосед, пригодный для поселения:** не вода, не руина без жилья, не
   режим без dwelling; сельский кап 5 на гекс (городской кап 20 — по ADR 0072 и решению
   владельца) учитывается отдельно от пригодности.
2. **Пригодность — правило места, а не счётчик дворов:** `can_settle` обязан смотреть на
   terrain/regime, иначе правило читается как «где есть место, там и живём».
3. **Все шесть заняты/непригодны — двор остаётся** и голодает по-настоящему; «некуда» — не
   повод уйти в воду.
4. **Глобального капа плотности не заводим:** новый слой и ломает локальное правило
   `TILE_MAX_HOUSEHOLDS`. Плотность на 100×100 меряем отдельно (ADR 0073), а не
   зашиваем в правило.
5. Один гекс на месяц: волна миграции локальна, уход не перескакивает через клетки.

## Проверка

```bash
bash sim/run_tests.sh
PYTHONPATH=sim/src python3 -m unittest sim.tests.test_migration_candidate -v
```

Критерий: сюит зелёный; тест «кандидат в воду/руину без жилья отклонён»; «шесть заняты —
двор остаётся»; детерминизм и дельта 0; каноны в окнах §1.

## Что запрещено следующим агентам

1. Считать «пригодность» только капом дворов.
2. Вводить глобальный кап плотности или cap на карту без отдельного ADR владельца.
3. Убирать двор «насильно», если все соседи непригодны.

## Альтернативы

- **Глобальный кап плотности на карту.** Отклонено: новый слой, ломает локальное правило,
  карта станет «пробкой» из невидимого админа.
- **Миграция по любому свободному гексу (как сейчас).** Отклонено: дворы уходят в воду и
  руины, каноны меряют не тот процесс.

## Последствия

- Кандидаты миграции сужаются; часть дворов будет оставаться чаще — это честно.
- Числа канонов после исполнения могут сдвинуться (уходов меньше, дворы не исчезают); окна
  §1 не меняются, сдвиг объявляется открытым ADR исполнения.
