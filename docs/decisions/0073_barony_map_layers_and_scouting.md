# 0073. Баронство как земля: слои, два контура, разведка как источник знания (владелец)

Дата: 2026-09-24. Развивает 0070 (гекс = место) и 0071 (шестиугольная сетка) по требованию
хозяина: карта должна вмещать события, налоги, торговлю, реку/пристани, экспансию и давать
тайну собственной земли (отшельник, привал, дым) — без тысяч агентов.

## Контекст

- Хозяин: агенты «схлопнуты» на уровне деревни; тактически игрок видит гексы и двигает
  юниты пошагово; но карта должна быть большой (100×100), с рекой, пристанями, торговлей,
  караванами в/из соседних баронств, местами для редких событий и **исследования**: герой
  бежал с войны и поселился в глуши, его можно найти только если кто-то прошёл рядом;
  охотник/лесничий замечает хижину, дым, костёр, дичь, а с башни/вышки видно дальше.
- Systems (0070/0071): подробно считаются поселения и дворы; гексы без поселений — coarse
  данные; дневной контур разрешён И-4 только для `Pack` в пути и активной опасности.
- Информация уже честна: `Report` с датой/каналом/шумом, `known_tiles` не растёт сам.

## Решение

1. **Гекс — данные, не агент:** 100×100 гексов = карта (террейн, режим, держатель, проходимость,
   тропа/дорога, указатель поселения). Агент — поселение/двор; гекс меняется только если
   по нему прошёл `Pack`, идёт стройка, помещается поселение или барон что-то приказал.
2. **Два контура, оба уже законны:** месячный — поселения, экономика, право, повинности, рост
   троп, отправка/прибытие обозов по месяцам; дневной — **только движущееся**: `Pack`
   в пути (ETA по дням, 0069), колонна (гекс = отряд/обоз, 0070), разведочная партия
   (`Pack.kind=party`, цель — разведка), активная опасность. Никто не обходит всех людей.
3. **Разведка — источник знания, а не новый агентный слой:** партия/охотник/лесничий/
   башенный дозор проходят гексы и **наблюдают** по правилам (видимость по террейну и
   высоте, шанс заметить от покрова/профиля, без «случайной магии»); найденное приходит
   `Report` с датой и каналом. Гекс становится известным **только** из доставленной вести.
4. **Редкие места открываются поиском:** отшельник/хижина/заставка — событие, привязанное к
   гексу, обнаруживается лишь разведкой рядом (следы, дым, костёр); найденное — обычное
   поселение в 1 двор (иначе — ярлык без жилья). Никаких «случайных» откровений издалека.
5. **Река и порты:** водные гексы, брод/мост, гекс-пристань (поселение с водным доступом);
   суда — `Pack` (`caravan` по воде), экспорт/импорт через порт и караваны в соседние
   баронства; выход за пределы карты — путешествие (ADR следующего этапа), не новая карта.
6. **Событие привязано к гексу** и меняет его режим/держателя/метку; масштаб события
   задаётся гексом, а не числом агентов.

## Альтернативы

- Случайные события без разведки (генерация от тика) — отклонено: всеведение и дешёвый шум;
  хозяин прямо хочет, чтобы отшельника можно было *не найти*.
- Агент на каждый гекс — отклонено: нагрузка и И-4.
- Отдельная «тактическая симуляция» вне карты — отклонено: движение по карте уже есть
  (`find_path`, `Pack`), дублировать нечего.

## Последствия

- Реализация после сетки/времени: Implementer (разведочная партия + `party`-цель, дневное
  разрешение `Pack`), Info (канал наблюдения, `Report` о находке), Systems (проект правил
  наблюдения), World (карта 100×100: река/порты/лес/пашни/ wilds), Scribe (доки `03`/`05`).
- Баронство в игре крупное (≈1 600 км²) — сознательное игровое допущение, не историческая
  норма; зафиксировано, чтобы не «чинили» цифры.
- Каноны не сдвигаются: карта растёт, а не числа.

## Что запрещено

1. Открывать гексы/места без доставленной вести (И-3).
2. Генерировать события от тика без условий и без поиска.
3. Дневной контур для всех людей (И-4).
4. Заводить агента на гекс без поселения/ Pack.
5. Обещать экспансию за пределы карты без отдельного ADR владельца.

## Проверка

```bash
bash sim/run_tests.sh
```

Критерий: сюит зелёный; разведка в 2 гексах видит, в 4 — нет; находка приходит вестью с
датой; гекс без вести остаётся неизвестным; дельта 0; каноны в окнах.
