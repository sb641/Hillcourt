# 0027. Река как дорога: вода, плот, брод (зона ВОДА)

## Контекст

Задача сессии «ВОДА»: река — дорога с другим профилем и другим судном.
Ограничения: сухопутный pathfinder — подключить, не форкать; службу тэна,
скот, вид тайла, yield — не трогать; флот и шхуны не строить; одна река
в существующих сценариях, новую карту шира с нуля не рисовать; судно ест
труд и материал из существующих брёвен/труда; течение в первой итерации
не обязательно; обоз с телегой реку в чаще не перепрыгивает.

Ролевой разбор (субагент, Muse Spark 1.3 Free, второй взгляд на замысел):
1. Солевар у реки — приму, если плот не ест мой труд и торф, а везёт только
   готовую соль (стройка плота — не у варниц, руки варки не трогаем).
2. Хозяин обоза — приму, если перевалка одна, плот не тащится по суше,
   а телега не ломается и не превращается во флот (вода — три клетки,
   дальше снова телега).
3. Держатель холма — приму, если нет микроменеджмента флота, рента считается
   как раньше, а канон соли 15.6 держится.
4. Плотовщик — приму, если без судна воды нет, брод остаётся дорогим риском
   для суши (пеший брод — отчаянный шаг, а не норма), течений нет честно.
Вывод разбора: воду принимаем как дорогую перевалку с платным судном
из брёвен, без слома соли, ренты и сухопутных правил.

## Решение

1. Какие клетки в каком сценарии стали водой: только `v0_shire.yml`
   (остальные сценарии не тронуты). Река — три клетки:
   `t_03_03` (была `marsh`), `t_04_03` (была `heath`), `t_04_04`
   (была `marsh`); знак `~: water` в легенде; брод `fords: [[4, 4]]`
   на `t_04_04`. Берега: запад `t_03_04` (руина), восток `t_05_04`
   (пустошь) — суша. Манхэттен-обозы соли (y=5/x=1) и зерна (x=2) реку
   не пересекают: сухопутный соляной воз жив тем же маршрутом.
2. Благо vessel: `goods.yml` — `raft` (Плот) и `boat` (Малая лодка),
   `category: material`, `storage: barn` (как телега, не из воздуха).
3. Рецепты: `craft_raft` (`log` 3.0 → `raft` 1.0 + потери `log` 2.0,
   труд 12) и `craft_boat` (`log` 4.0 + `firewood` 0.5 → `boat` 1.0 +
   потери 3.0/0.5, труд 16), оба `transform: true`, баланс сходится;
   `idle_repair` строит и их. Проверка: зонд строит плот из брёвен,
   `log` 3.0 → 0, `raft` → 1.0, дельта материи 0.
4. Профили хода (`engine/terrain.py`, подключением к сухопутному модулю):
   `water_raft` (вода 1.0, суша 5–10) и `water_boat` (вода 0.8, суша 5–10).
   Сухопутные профили как были: вода без брода/моста — `IMPASSABLE`.
   Речные идут рекой без брода; течения нет (вверх/вниз одинаково).
   Добавлены предикаты `is_water_profile`/`is_land_profile`.
5. Приказ `engine/river.py::send_river_pack` (новый файл, форка нет):
   маршрут — `find_path` по речному профилю через известия игрока
   (`known_tiles`, И-3); в маршруте обязана быть вода, иначе это суша
   (`send_march`); без судна (`raft`/`boat` ≥ 1.0 в стоках двора+склада)
   большой груз (> 1.0) не едет — `ValueError`; ноша ≤ 1.0 — отчаянный
   брод. Воз — `Pack kind="caravan"`: разгрузка, фураж и риск опасных
   клеток маршрута — существующий `resolve_caravans`/`strongest_hazard`
   (отдельного флота и резолва нет). Судно в пути не расходуется
   (как телега «в инструменте»); риск воды без опасности — честный
   свободный проход («паводка нет»), с опасностью — тот же контур
   (`base_risk_for`, у `bog` 0.1). `runner.py` — только handler `send_river`
   (рядом с чужими `send_sally`/`work_*`, их строки не тронуты).
   `scenario.py` — только секции `fords`/`bridges`/`roads` поверх карты
   (обратно совместимо) плюс ошибка на знак вне легенды.
6. Зонды `sim/tests/test_river_raft.py` (17):
   «плот построен → груз по реке» (`test_raft_built_then_cargo_goes_by_river`:
   плот из брёвен рецептом, `send_river_pack` с зерном 4.0 идёт маршрутом
   с водой, `Pack kind="caravan"`, приказ `send_river` в логе, дельта 0);
   «без плота тем же маршрутом не то же самое»
   (`test_no_vessel_no_large_cargo_same_route`: тот же origin/dest/груз
   без судна — `ValueError`, воз не создан). Закрытие по условию сдачи:
   Pack по реке ходят (создание + разгрузка в склад `fs_09` через
   `resolve_caravans`, дельта 0), сухопутный соляной воз выходит тем же
   манхэттеном в обход воды, телега без брода в воду не входит, брод
   пропускает пеших (2.5 против 1.0 плота).
7. `sim/tests/test_march_path.py` — правки под 6 профилей (подключение,
   не форк): список профилей, цены воды/чащи у речных, брод нужен только
   суше.

## Альтернативы

- Отдельный `kind="river"` со своим резолвом: отвергнуто — второй контур
  риска и разгрузки (форк каравана), вместо этого `kind="caravan"`.
- Перевести живые обозы на pathfinder, чтобы суша «видела» реку:
  отвергнуто — запрет ADR 0023 (сдвинет риск/RNG/хеши); манхэттен оставлен,
  река положена мимо его линий.
- Течение (вниз дешевле): отвергнуто для первой итерации — нет данных
  направления на карте; минимум «два берега и брод» закрыт.
- Новый hazard `rapid`/«паводок»: отвергнуто — риск идёт существующим
  контуром (`bog` на воде виден тем же `strongest_hazard`); без опасности
  проход свободен честно.

## Последствия

- Приёмка: `bash sim/run_tests.sh` — 362 OK (17 новых речных зелёные);
  канон держится: `v0_hill_and_salt` 36/1729 — соль 15.6, дельта −0.000000,
  живых 12, голод 33; `v0_two_settlements` 60/42 — соль 15.6, дельта
  −0.000000, живых 18 (окно 17–19), голод 284; `v0_shire` 60/1729 —
  соль 15.6, дельта 0.000000, живых 28 (окно 26–28), голод 541 (> 0).
  В `v0_hill_and_salt` за 36 мес ни одного плота/лодки не построено
  (проверено по леджеру) — автовыборка канон не сдвинула.
- Хеши `state_hash` — снимок ревизии, не окно (конкурирующие смены меняют
  экономику параллельно); окна соли/живых/голода/дельты соблюдены.
- Scribe: новых сущностей онтологии нет (`water`/`ford` уже в `Tile`,
  судно — каталог, воз — `kind="caravan"`); по желанию — `send_river`
  в список `PlayerAction` `docs/03_ontology.md` новым ADR.
- Ролевой вердикт сошёлся: солевар не платит трудом (плоты строят из
  брёвен вне варниц), обоз держит телегу на суше, держатель не получил
  микроменеджмента, плотовщик получил дорогой брод и честную воду.

## Что запрещено следующим агентам

- Строить флот: новые суда/профили/«порты» только новым ADR; `water_*`
  не таскать грузы по суше (суша им дорога не просто так).
- Переводить `economy/caravan.py` и `phase_migrate` на pathfinder без
  нового ADR (запрет 0023 в силе).
- Вводить течение/направление без данных карты и зонда «вверх ≠ вниз».
- Расходовать судно в пути молча: судно — инструмент (как телега);
  износ — только явным правилом с зондом и балансом.
- Класть новые реки в `v0_hill_and_salt`/`v0_two_settlements` без ADR
  с пересмотром окон приёмки (их манхэттен-линии заняты).
- Читать `Tile`/`Stock` неизвестных клеток для выбора речного пути
  игрока; обогащение `Report.facts` террейном — только новым ADR.
