# 0025. Стройка пути: дорога/брод/мост как проект барщины (стык с path/water)

## Контекст

Задача «СТРОЙКА ПУТИ»: дорога не рисуется в редакторе — её кладут дни рук и
материал. Игрок (корень) ставит работу на клетке своей книги, дни идут из
барщины/найма уже существующего пула труда, пока проект не готов — клетка
старая, готовая дорога дешевит ход обоза. Стык двусторонний: сухопутный
`engine/path.py` + `engine/terrain.py` (ADR 0023) уже читают tag
`road`/`ford`/`bridge`; водная зона (параллельный агент: `engine/river.py`,
профили `water_raft`/`water_boat`) идёт по воде без брода, а брод нужен суше.
Ограничения: не трогать службу тэна, скот, суда (водный код не переписывать —
только works на клетке), вид тайла читать без смены капа пяти дворов, yield
не поднимать. Не закрыто, если дорога «просто есть» без проекта.

## Решение

1. `sim/src/hillcourt/engine/roadworks.py` — реестр `world.roadworks`:
   `start_work(tile, kind)` (`road`/`ford`/`bridge`; действия
   `work_road`/`work_ford`/`work_bridge` в `runner.py`): террейн-гейты
   (дорога — не на воду; брод/мост — только на воду), запрет дубля tag и
   второй стройки, книга корня (клетка тэна — `PermissionError`, сначала
   отзыв, как `set_tile_regime`; служба тэна не тронута), материал `log`
   (4/2/6) переводом амбар корня → `sink:waste` (`roadwork_material`,
   И-1 держится переводом). Лог в `World.player_actions`.
2. Труд — из остатка `Household.labor_days` после барщины манора, до поля:
   фаза `phase_roadworks` в `tick.py` стоит после `phase_manor`, до
   `phase_labor`; на стройку — до 12 дней/мес (дорога 30, брод 20, мост 40:
   2–4 месяца). Без рук прогресса и завершения нет. Поле худеет честно;
   спрос домена/барщина видны как раньше (`manor_log`, `corvee_days`), плюс
   `roadwork_days` в `stats`. Отдельный A* не копируется: завершение один раз
   поднимает tag клетки, дальше считают `entry_cost`/`find_path` и речной
   контур без изменений.
3. `World.roadworks` + условные части хеша (`way|`, `roadwork|` только при
   непустом): пустые работы канон не сдвигают. Вид тайла только читается
   (`TILE_MAX_HOUSEHOLDS` 5 не менялся), yield/seasons не тронуты.
4. Зонды `sim/tests/test_roadworks.py` (16): старт пишет `player_actions` и
   держит старый cost/tag; дорога 8.0 → 0.8 у `caravan`, дни `find_path`
   падают; брод открывает воду сухопутным; мост ставит `bridge`; без рук
   (`labor_days` 0) прогресса нет; поле теряет руки; материя 0 при активной
   стройке; соль идёт `caravan_load`/`caravan_unload`, `external_in` соли нет.
5. Ролевой разбор (субагент, Muse Spark 1.3 Free): держатель платит дважды
   (брёвна сразу, до 12 дней/мес 2–4 месяца, выгоды ноль до tag); виллан
   теряет свой надел честно и смысла в процессе не видит; хозяин обоза едет
   по-старому месяцы стройки, потом чаща 8.0 → 0.8 навсегда, брод сшивает
   реку; шериф выигрывает скорость мира (меньше задержка приказа), но брод —
   узкое место. Строить стоит, если брёвна в амбаре, руки после барщины без
   голода поля, а клетка режет реальный маршрут или сшивает реку.

## Альтернативы

- Труд из доменного пула (конкуренция с урожаем замка): отвергнуто — требует
  правки `economy/manor.py` (чужая зона Economist) и рискует каноном замка;
  остаток после барщины даёт тот же честный эффект на поле без форка.
- Материал без списания / дорога флагом в сценарии: отвергнуто — И-1 и прямой
  запрет задачи («просто есть» — не закрыто).
- Свой pathfinder для обоза: отвергнуто — ADR 0023 запрещает форк; сдача =
  клетка меняет tag и cost, живые обозы (манхэттен) не тронуты.
