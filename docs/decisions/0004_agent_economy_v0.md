# 0004. Агентная экономика v0 (Economist)

## Контекст

Фаза 0 дала каркас: `Ledger`, каталоги, месячный тик, известия. Но дворы не были агентами:
`phase_labor` механически применяла все рецепты, пока хватало труда; не было потребностей,
действий, страха, износа инструмента, локального обмена и решения «работать или рискнуть».
Каталог из 5 товаров не описывал мешок, воз и трудодень. Задача сессии — собрать работающую
агентную экономику одной баронии (24–36 месяцев headless), не нарушив И-1 и не раздувая объём.

Роль: Economist. Зона правки: `design/catalogs/{goods,recipes,spawn_rules,hazards,needs,
actions_household}.yml`, `sim/src/hillcourt/economy/`. Смежные файлы (`ontology.py`, `tick.py`,
`scenario.py`, `runner.py`, `tests/`) правлены точечно как Implementer-проводка.

## Решение

1. **Каталоги экономики.** 18 товаров (`grain/flour/meat/straw/firewood/log/peat/hay/salt/
   brine/iron/wool/cloth/hide/axe/silver/pig/horse`); 16 рецептов с полями вход/труд/место/
   время/отход; `needs.yml` (рот/месяц, корм скота, дрова зимой, износ топора, подмога);
   `actions_household.yml` (10 действий v0, из них экспедиция к руине — заглушка).
   Единицы описаны в `design/catalogs/README.md`: `unit` = мешок, `labor_days` = трудодень,
   воз = 40 unit (в v0 обоз только как `Report`).
2. **Двор как агент.** `Household` получил `main_action`/`minor_action`, `adventurism 0..1`,
   `rumor_fear 0..1`, `tool_wear`, `traveling`. Запас еды = съедобная масса / месячная
   потребность по `needs.yml`. Решение — 1 главное + 1 мелкое действие на месяц
   (`economy/decisions.py`): подмога при затяжном голоде → еда → зимнее топливо → починка →
   скот → риск. Авантюризм = интерес (любопытство) минус страх и цена рук на поле; при высокой
   опасности и низком авантюризме двор не идёт в чащу (`should_venture`).
3. **Тик месяца.** Порядок фаз: `season → growth → labor → spoil → consume → obligations →
   exchange → hazard → migrate → decide → inform → record`. Производство — только через
   рецепты, разрешённые выбранными действиями; `travel_adjacent` снимает руки с поля.
   `decide` в конце месяца выбирает действия на следующий.
4. **Обмен и подмога.** `exchange.py`: локальный обмен на клетке (свиньи за серебро, зерно
   между сытым и голодным), подмога из стока замка, тайники от волков. Всё — `Ledger.transfer`,
   ни одного `external_in`; обмен не создаёт материю.
5. **Износ.** Топор тупится только на «топорных» рецептах (`needs.tool.wear_recipes`), масса
   уходит в `sink:waste`; ниже порога топор ломается. Свинья плодится только при паре
   (`pig ≥ 2`), расходуя производителя (`farrow_pigs`: 1 свинья + 6 сена → 2 свиньи + 5 потерь),
   не более одного опороса в месяц.
6. **Потолок природы.** У каждого `grow_*` появился `cap_per_tile`; `phase_growth` клампит
   приход. Иначе природа — бездонный кран, а узкое место исчезает (находка BalanceCritic).
7. **Сценарий.** `v0_hill_and_salt.yml`: 63 клетки, 12 поселений (10 farmstead + hill_court +
   salt_village), 14 дворов разной сытости и нрава, дальняя соль, лес с волками у холма.
8. **Лог прогона.** `runner` печатает по месяцам: запасы замка, живые дворы, собранную ренту,
   число ходок на соседнюю клетку, ушедших и не вернувшихся людей, голодные месяцы.

## Альтернативы

- **Держать прежний механический `phase_labor`** — отклонено: двор не агент, нет голода и ухода.
- **Сделать `farrow_pigs` без расхода производителя** — отклонено после BalanceCritic:
  поголовье росло без ограничения (2 свиньи + сено → 7 за месяц).
- **Без `cap_per_tile`** — отклонено: standing рос линейно и вечно, «рай из природы».
- **Обмен через `external_in`** — отклонено: создал бы серебро/товар из ничего. Только `transfer`.
- **Ренту-долю считать от фактического сбора** — отложено: `rent_amount_for` в зоне Legal,
  сейчас `basis: share` использует базовый мешок, а не урожай (см. `docs/decisions/0003`).

## Последствия

- Экономика проверяется `sim/tests/test_household_economy.py` (6 тестов): голод без еды/труда,
  перевод ренты, свинья только за куплю/приплод, приплод от пары, `travel_adjacent` снимает
  руки, страх держит вне чащи.
- Прогон 36 месяцев: дельта материи `0.000000`, есть голодные месяцы и ушедшие без возврата
  дворы, известия датированы. 120 месяцев — без падений и с нулевой дельтой.
- **Не реализовано (deferred):** экспедиция к руине — заглушка без лута; `requires_tool`
  проверяется лишь частично; трудовая повинность только копит `corvee_days`, не отнимая труд;
  `spawn_rules` для hazard/pack/ruin не исполняются (см. `docs/02`).

## Что запрещено следующим агентам

1. Убирать `cap_per_tile` или `phase_growth`-кламп — это возврат бездонного крана.
2. Делать `farrow_pigs` без входа `pig` или разрешать больше одного опороса в месяц.
3. Вводить `external_in` в обмен/подмогу/тайники: там допустим только `transfer`.
4. Считать топор вечным: износ обязан уводить массу в `sink:waste`.
5. Писать производство вне рецептов и вне разрешённых действий двора.
6. Трогать каталоги Legal (`obligations/rights/land_regimes/legal_statuses/offices`) в этой зоне.

## Проверка

```bash
bash sim/run_tests.sh
PYTHONPATH=sim/src python3 -m hillcourt.runner \
  --scenario design/scenarios/v0_hill_and_salt.yml --months 36 --print-log
```

Критерий: все тесты зелёные; в логе есть хотя бы один голодный месяц **или** ушедший без
возврата человек; `дельта материи 0.000000`; каталог `test_catalog_rules` зелёный.
