# 0030. Скот и железо из hollow в живые: крица, сено, конь, стартовые пары

Дата: 2026-09-21. Цикл по хендоффу Economist (аудит hollow-систем). Роли: Economist
(каталог + `economy/`), Implementer (стартовые наборы шира); стол — Game Owner (закон).

## Контекст

Независимый аудит показал: ни один сценарий не стартует со скотом и спавна нет
(`gather_hay` 0 проводок, сена 6.3, волы гибнут раньше отдачи, `draft_*` мёртв);
`iron_share` — только товар без рецепта/спавна, `iron_bloom` не производится
(только вход `smith_kit`), поэтому `smith_kit` мёртв, а второй тэн 0/19 по норме;
`mine_iron` даёт `iron` (18.8) в никуда; `craft_wooden_plough` недостижим (`log` 0).
Заявленный краш `_work_demesne` с лемехом в этом дереве (364) НЕ воспроизвёлся —
проверка уже идёт через `combined`, чинить было нечего.
Рамки хендоффа: дельта 0; соль 15.6; живые в окнах; голод > 0, не массовый; yield не
поднимать; сдвиг канона — только ADR, не подгонка.

## Решение

**Economist (каталог + `economy/`, без сценариев):**
- Рецепт `smelt_iron_bloom` (`iron 1.2 + firewood 0.6 → iron_bloom 1.0`, потери
  `iron 0.2 + firewood 0.6`, труд 10, `transform`, баланс 1.8 = 1.8): закрывает И-7
  (у крицы есть производитель — рецептом, но потребитель живой: только вход `smith_kit`).
  К действию НЕ подключён:
  проводка (`work_plot`/`idle_repair`) сдвигала канон — подключение требует ADR.
- `can_hold_horse` стал механизмом: `draft_goods_for` (конь — только `free`, вол/осёл —
  всем), гейт в `draft_plough_factor` и `origin_draft`, проводка в `decisions`
  (`tend_animals` считает только своё тягло). `tied`-двор с конём бонуса не получает.
- Сено: `gather_draft_hay` в `livestock_month` — двор с тяглом докашивает с доступных
  пастбищ из остатка труда после поля, рецептом `gather_hay`. Без скота фаза пуста,
  RNG не тратится.
- Дропнуто с причинами: крафт `iron_share` (бонус держим редким); спавн скота
  (магия; внешний обмен запрещён ADR 0004 — только `transfer`; приобретение — стартовые
  наборы/покупка); досягаемость плуга (`cut_wood` не видит `reserved_wood`, бюджет
  `idle_repair` 8 < 10 — доступ к лесу вне суженной зоны и меняет канон).

**Implementer (только `v0_shire.yml` + тест), финал после ПРОТИВ Виллана:**
- Три пары вне караванных поселений (соль не задета): волы `hh_11` (`fs_11`, villein —
  там вяжет труд, а не кап), ослы `hh_14` (`fs_14`, geneat), кони `hh_09` (`fs_09`,
  geneat — конь у свободного); сено `hh_11` 42.4 / `hh_14` 17.0 / `hh_09` 19.0;
  `hh_10` — базовые `hay: 5.0` без скота, `hh_12`/`hh_13` — без скота и сена (медиана 0).
  Промежуточная раскладка (волы `hh_10`) отменена: у коттера кап 0.5 вяжет раньше рук.
  Молодняк/железо/суда не клались.
- Критерий пар — анти-голод, а не бессмертие: `test_pairs_do_not_starve` требует 0 проводок
  `starved` по товарам пар за 12 мес (естественный `died` 0.5%/мес допускается); голод
  срезает лишь приплод сверх пары. Негативный контроль (сено 30) — FAIL, как положено.

## Альтернативы

- Подключить выплавку к действию сейчас — отклонено: сдвиг канона без ADR.
- Спавн скота правилом — отклонено: магия без капа и обоснования (И-7/И-1).
- Плуг через доступ к соседнему лесу — отклонено: вне суженной зоны, меняет канон.
- Не класть наборы вовсе — отклонено: скот остался бы мёртвым кодом при живом законе.
