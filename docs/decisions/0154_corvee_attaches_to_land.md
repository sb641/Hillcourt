# 0154. Барщина держится за землёй. Безземельный свободный не барщит, а нанимается

## Контекст

Разведка падений нашла корень семи красных тестов в четырёх модулях — **одну строку**:
`sim/src/hillcourt/legal/calendar.py:113-117`. Для пресета `free_landless` функция
`seasonal_labor_days` возвращает `adults × ADULT_LABOR_DAYS` — то есть **100 % трудодней
взрослых в сезонную барщину**.

Это противоречит трём вещам сразу:
- **бандл `free_landless_none` пуст** — `design/catalogs/obligations.yml:74-77`, ни одного
  числового условия;
- **`docs/07_legal.md:95`** прямо пишет: для `free_landless` это `hire_demand low|high`, то есть
  **наём, а не долг**;
- **ADR 0131**, который держит юрист: «барщина — **бесплатный труд**, выплат нет», и подписная
  мысль хозяина — «барщина — плата за **землю**, сословие и закон».

Следствие видно не только в тестах, а в игре: безземельный свободный **не может наняться**
(`capacity = labor_days = 0` после `_render_pool`, `economy/manor.py:209-225`), **не может
кормить своё хозяйство** (`own_budget = 0`, `economy/labor.py:843`) и не может производить
ничего. То есть выбит из игры сам источник наёмного труда.

Падения: `test_adr0105:121`, `test_established_holder_not_starving:164,182`,
`test_household_economy:124` (тот самый `farrow`, который я велел не чинить),
`test_manor_economy:138`. Остальные четыре — производные.

## Правила

1. **Барщина держится за землёй, а не за сословием.** Двор, у которого есть надел, барщит.
   Двор без надела не барщит — его нанимают. Это следует из ADR 0131: барщина есть плата за
   землю, а у безземельного земли нет, платить не за что.
2. **`free_landless` сезонной барщины не имеет: 0 трудодней.** `seasonal_labor_days` для этого
   пресета возвращает **0**, а не `adults × ADULT_LABOR_DAYS`. Найм идёт через
   `hire_demand low|high` (ADR 0120), двор получает **харчи и серебро** — оба канала, как требует
   ADR 0120 и ADR 0131.
3. **Это уточняет формулировку ADR 0173 п. 1, а не отменяет её.** ADR 0173 перечисляет
   «сокольники, фримены, невольники, все» под корнем «**обязанное барщиной по сослову**».
   Обязанность порождается **наделом**: сокольник и свободный держатель земли барщат, безземельный
   свободный — нет. Слово «фримены» в ADR 0173 означает свободных **с землёй**; безземельные
   свободные — отдельное сословие по найму. Оговорка сделана здесь, потому что формулировка
   ADR 0173 без неё противоречит пустому бандлу.
4. **Невольники и коттеры барщат по-прежнему.** У невольника земли нет, но он не свободный и не
   наёмный: он ест паёк и работает на домен (ADR 0131). Это исключение из п. 1, и оно явное.
5. **Потолок заработка и выплаты не меняются.** Барщина бесплатна (ADR 0131), найм платный
   (ADR 0120), серебро не создаётся (ADR 0101).

## Проверка

```bash
PYTHONPATH=sim/src python3 -m unittest sim.tests.test_adr0105 sim.tests.test_established_holder_not_starving sim.tests.test_household_economy sim.tests.test_manor_economy -v
```

- `seasonal_labor_days` для `free_landless` — **0** трудодней в любом месяце.
- Безземельный свободный **нанимается** и получает **харчи и серебро** оба.
- У него ненулевой `own_budget`: двор может вести своё хозяйство.
- Сокольник, виллан, коттер, невольник — сезонная барщина **не изменилась** (регрессия).
- Выплаты за `labor_duty` — **0** во всех сословиях (ADR 0131).
- Дельта материи **0**, детерминизм по одному `seed`.

## Что запрещено следующим агентам

- Возвращать `free_landless` сезонную барщину.
- Нанимать двор, у которого есть надел: он работает своё хозяйство, его доход это надел (ADR 0131).
- Трогать невольников и коттеров — они барщат.
- Снимать невольника с пайка «закон, что у него нет земли»: невольник ест паёк и работает.
