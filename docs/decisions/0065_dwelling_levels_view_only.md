# 0065. Уровни домов и таверна: v1 только видом (владелец)

Дата: 2026-09-24. По проекту World (цикл 36) и стади-гейту Systems.

## Контекст

Видение хозяина: «двор может иметь палатку из земли, дом, двух-этажный дом; у зажиточного
двора — конюшня/маслобойня; в городах — таверна». World разобрал: формат тайла не может
показать уровень отдельного дома, авторитетного поля уровня нет, `tavern_site` — только
место. Признак «мастер» Economist: в v1 не вводим (новая онтология без механики = ярлык).

## Решение

1. **v1 — только вид, из сценарных маркеров.** Маркер `dwelling` со значениями
   `tent_earth` / `house` / `multi_storey` → формы `tent_earth_homestead` /
   `timber_house` / `multi_storey_house`; `tavern` → существующая форма `tavern_site`
   (участок, не построенная таверна). Смешанные уровни в одной деревне (2+ двора) не
   выражаются — остаётся `village`/`tribal_village`.
2. **Никаких бонусов и полей:** маркер — данные сценария (`marks:`), тик его не пишет и не
   читает; И-5 цел; авторитетного `housing_level` в v1 нет.
3. **ADR-вопрос отложен:** если уровень станет состоянием, владелец поля — `Household`
   (дом) или `Tile` (клетка) — решается отдельным ADR вместе с переходом (стройка/улучшение/
   разрушение) и ценой (материалы, труд, право барона, хранение, тепло, престиж).
4. **Мастерство — знание, не поле:** «двор-кузнец» приходит вестью по наблюдению (дым/звон/
   товар на рынке), не новым полем экономики. Тексты — за Info.

## Альтернативы

- `Household.housing_level` сейчас — отклонено: поле без перехода = ярлык (тот же брак,
  что `loyalty`/`muster_profile` в 0064).
- Переиспользовать `tent_camp` под земляной дом — отклонено: это временный лагерь.
- Таверна механикой сейчас — отклонено: здание, труд, корм, выручка, постой — ценный слой,
  открывается своим ADR.

## Последствия

- Реализация: World (формы и пины, зона `tile_view.py`) + поддержка секции `marks:` в
  загрузчике (Implementer) — только когда это не конфликтует с текущим срезом.
- Холостые формы без данных сценария — не ошибка (dump покажет, чего нет).

## Что запрещено следующим агентам

1. Давать маркерам бонусы/штрафы (view-only, И-5).
2. Вводить `housing_level` без ADR с переходом и ценой.
3. Выдавать `tavern_site` за построенную таверну (блюда, выручки, постоя нет).
