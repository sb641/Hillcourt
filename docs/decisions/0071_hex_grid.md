# 0071. Шестиугольная сетка: гекс — единица места (владелец)

Дата: 2026-09-24. Уточняет 0070/0069 по калибровке Systems. Открывает этап «большое баронство».

## Контекст

Хозяин: тайл на карте — ромбовидный шестиугольник; один гекс = место (деревня/квартал/
позиция колонны). Systems: код сейчас квадратная 4-соседская сетка и сутки на клетку; при
гексе ≈ 0,4 км переход 100 гексов = 50–80 ч ноги (2,1–3,3 суток), диагональ 141 гекс =
3–5 суток — критерий «переход баронства за 2 сутока» читать как **100 гексов**, не диагональ.
Ёмкость пастбища на гекс (2 вола/4 осла/5 свиней) сохраняется модельной.

## Решение

1. **Сетка — шестиугольная**, аксиальные координаты `(q, r)`, 6 соседей. Квадратная сетка
   кода заменяется **механически**: соседство, `find_path` (алгоритм и эвристики не трогаем),
   координаты сценариев, `roadworks` (соседние клетки), `tile_view`, хеш состояния, тесты.
2. **Никаких механических изменений в этом этапе:** ни выходов, ни труда, ни материи, ни
   окон. Только топология и координаты; все числа остаются как есть.
3. **Часы на гекс (якоря):** нога 0,65 ч в поле, конь 0,40, обоз 0,85, пешая армия `arms`
   ≈ нога ×1,25; пропорции террейнов нынешние (`hill/forest/marsh` дороже `field/pasture`),
   тропа ×0,9 / грунт ×0,8 / `road` как min; вода без переправы непроходима; водные профили
   получают отдельный якорь. Время в часах (плавающее), не в сутках.
4. **Критерий размера:** переход 100 гексов ≈ 2–3 суток пешком; диагональ 100×100 ≈ 3–5
   суток; обозом +50%. Критерий 0070 уточнён этой строкой.
5. **Порядок:** сетка → временная шкала (0069/0070) → слои/кольца знания → городские
   кварталы (0072) → походный гекс колонны (v2 вызова).

## Альтернативы

- Оставить квадратную сетку, рисовать шестиугольниками — отклонено: соседство и радиусы
  знания считались бы по чужой метрике; дешевле сделать честно один раз.
- Гекс = 6 соседей, но диаметр 0,4 км «по ребру» — отклонено: площадь гекса тогда ≈0,12 км²;
  площадь уточняется отдельной калибровкой, на калибровку часов это не влияет.

## Последствия

- Большой механический срез (сетка), но без правил: сюит должен остаться зелёным, каноны
  бит-в-бит по числам (хеши сменятся — открыто).
- Сценарии и виды перегенерируются; `state_hash` покрывает новые координаты.

## Что запрещено

1. Менять вместе с сеткой экономику/тайк/окна.
2. Считать гекс квадратным километром.
3. Квантовать время сутками (минимальная единица — час).

## Проверка

```bash
bash sim/run_tests.sh
```

Критерий: сюит зелёный; соседство 6; путь через реку без переправы невозможен; каноны
