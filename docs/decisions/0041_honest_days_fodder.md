# 0041. Допуск №3: фураж по честным дням пути (Economist, вариант B)

Дата: 2026-09-23. Роль: Economist. Третий допуск по ADR 0038 (вариант B из
решения по стройке, STATUS цикл 2). Старые ADR не правятся. Зона строго своя:
`economy/caravan.py`, комментарий `spawn_rules.yml`, тест своего модуля.

## Контекст

`_fodder_amount` множил `fodder_per_day × entries` — имя врало: мощение коридора
соли 19 → 12 дней не меняло фураж ни на зерно. Замер (шир, свежий сценарий):
соль — 15 входов / 19.0 дн, фураж 0.75; мощёный — 12.0 дн, фураж был бы 0.75.
Предзарегистрированный критерий Critic: two держит ≥ 14; просадка до 13 —
открытое решение о перебазировке, а не «замер». База — канон цикла 8
(hill 12/15.6/31, two 14/15.6/341, shire 26/15.6/547).

## Решение

Фураж — по честным дням маршрута (`_route_days`: сумма дней входа после origin,
те же дни, что видят `find_path` и `eta`): соль немощёная 0.75 → **0.95**,
мощёная — **0.60** (дорога впервые экономит и торг — только фуражом, не
расписанием: `eta`/каденция не тронуты). При отправке дни берутся из `find_path`
напрямую; при разгрузке — пересчётом по текущим тегам (дорога, достроенная
в пути, тоже экономит — честно). Вода без переправы для сухопутного профиля
непроходима, а речной воз (`kind="caravan"`, `engine/river.py`) идёт водой своим
ходом: такой вход считается за **1.0 день** (как раньше счёт входов), иначе
бесконечность съела бы весь груз (`min(fodder, cargo)`). Риск, `eta`, каденция,
буфер, память сделки — не тронуты.

Сопутствующее: assert «фураж по входам» в `test_caravan_trade` обновлён на дни
(приказ меняет поведение — пин меняют вместе с ним, раскрыто здесь).

## Альтернативы

- Оставить счёт по входам — отклонено: имя `per_day` врёт, мощение не окупается
  ничем вообще (вариант C прошлого ADR — только приказы).
- Хранить дни в `Pack` при отправке — отклонено: поле онтологии, чужая зона без
  exemption; пересчёт по тегам детерминирован и даёт то же число без стройки
  в пути.
- Считать воду непроходимой и для речного (отказ/0) — отклонено: ломает речной
  воз; фолбэк 1.0 сохраняет старое поведение на воде бит-в-бит.
- Трогать `eta`/каденцию ради окупаемости — отклонено: механика торга вне
  допуска (вариант A выкинут хозяином).

## Что запрещено следующим агентам

1. Трогать `eta`, каденцию, буфер, риск, память этим допуском.
2. Менять фолбэк воды (1.0/вход) без нового ADR — за ним речной воз.
3. Класть дни в `Pack` без владельца онтологии.
4. Считать 13 в two «замером» — это перебазировка.
