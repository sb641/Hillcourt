# 0075. Водный контур v1: ёмкость судна, часы, река как сеть, порт без сущности (владелец)

Дата: 2026-09-24. По проектам Systems и Economist (цикл 54) для этапа «большое баронство».
Ставится **после** шестигранной сетки (0071) и часовой шкалы (0069/0070).

## Контекст

Сейчас вода = переправа: `water` гексы, `ford/bridge`, `raft`/`boat` (рецепты из брёвен),
`send_river` (маршрут по воде). Economist нашёл главную дыру: **ёмкости судна нет** — одна
лодка везёт что угодно, людей без капа; фуража и пошлины нет. Systems: реки как сети нет
(связность, исток/устье/притоки/течение), порт — только «поселение у воды», цена рынка и
таможня не выражены, `Obligation` не годится для анонимного судна (привязан к двору).

## Решение

1. **Ёмкость судна — закон (чинит безграничный транспорт):** груз `raft` 6.0, `boat` 12.0;
   люди `raft` 2, `boat` 4 взрослых. Судно везёт не больше; перебор — отказ. Это меняет
   экономику обозов: **окна меряются и правятся открыто** (two ≥ 14, shire 24–28 — гейт).
2. **Часовые якоря воды:** `water_raft` 0,17 ч/гекс, `water_boat` 0,14; вверх по течению —
   только `boat` с усилием ×1,5; `raft` вниз по течению (вверх — без груза или запрет).
   Тишина без направления течения не разрешает движение вверх.
3. **Река как сеть — сценарные данные:** секция `rivers` (`id`, исток, устье, притоки,
   порядок течения, выход к соседнему баронству); связность водных гексов проверяется, вода
   вне сети — не река. Сущности `River` в мире нет (не меняется в тике).
4. **Порт — поселение у воды:** склад = `Settlement.stores` (отдельный портовый склад не
   нужен), разгрузка — существующая `caravan_unload`, весть о прибытии — существующая.
   Вид/метка «порт/пристань» — ADR-вопрос (view/data), сущности `Port` нет.
5. **Пошлина — перевод, не повинность:** 10 % груза натурой в сток поселения при разгрузке в
   портовом гексе (`Ledger.transfer`, без серебра — его нет); соль (не еда) пошлину не платит.
   Долг пошлины (неоплата) — отложено (ADR-вопрос). Фиксированная рыночная цена — отдельный
   ADR (не смешивать с `barter_memory.ratio`).
6. **Фураж на воде — за ночёвку:** > 6 ч пути (переход суток) → фураж по дням; короткие
   рейсы без фуража честны (течение и ветер съедены в часах).
7. **Торговая барка/шхуна — отдельный ADR (не v1):** новый товар (И-7: storage+recipe),
   профиль `water_barge`, ёмкость ~40, экипаж 8, цена из брёвен/железа. Открывается после
   п.1–5 и замера портовой экономики.

## Альтернативы

- Оставить «лодка везёт всё» — отклонено: цена пути отсутствует, караваны/соль бессмысленны.
- Портовую пошлину делать `Obligation` — отклонено: повинность у двора, а груз анонимен.
- Текущую скорость воды (в 5–7 раз дешевле суши) оставить без пошлины — отклонено: река
  становится рельсами.
- Ввести сразу шхуну — отклонено: новый товар и профиль до ёмкости/пошлины = лишний слой.

## Последствия

- Реализация: Economist (ёмкости, часы, пошлина- transfer, фураж-ночёвка), Implementer
  (сценарий `rivers`, связность, upstream/downstream в `river.py`), Info (портовая весть),
  Scribe (`03`/`04`/`09`), World (вид порта). Проверка — стенд + каноны, окна открыто.
- Барка/шхуна: ADR после; экспансия по воде — ADR после пошлин.

## Что запрещено

1. Судно без ёмкости/капа людей.
2. Молчаливое движение вверх по реке без правила.
3. Пошлина через `Obligation` (привязан к двору) или серебром (его нет).
4. Смешивать `barter_memory.ratio` с ценой.
5. Открывать барку/шхуну до 0069–0075 п.1–5.

Критерий: сюит зелёный; перебор груза/людей — отказ; вверх по течению только по правилу;

дельта 0; окны — по новым замерам (открыто).
