# 0047. Чистка `travel_delay_months` (Economist)

Дата: 2026-09-23. Роль: Economist. Решение заготовки World (цикл 2): рычаг или
чистка, середины нет. Старые ADR не правятся. Зона строго своя (каталог).

## Контекст

Параметр `travel_delay_months: 1` жил в `hazards.yml:bog`, чтений — 0 во всём
репо, каталог сам помечал «в v0 не исполняется».

## Решение

Чистка: параметр удалён. Рычаг посчитан и отклонён: +1 день на топь при кванте
`eta = max(1, ceil(days/30))` не сдвигает ни одного срока (все маршруты < 30
дней) — весь «рычаг» сводился бы к +0.05 фуража на зерновозе через топь
(`t_02_04`): механика ради сотых + расход бюджета сложности (ADR 0038).
Заготовка без решения — ложь в каталоге; середины нет.

## Альтернативы

- Рычаг к дням воза — отклонено (см. выше: платит сотые, весит слой).
- Рычаг к логу приказов — отклонено: путь приказов — чужая зона без exemption.
- Оставить заготовку — отклонено задачей (ложь в каталоге).

## Последствия

Поведения нет (параметр никто не читал) — канон обязан стоять бит-в-бит,
включая хеши. Гейты two ≥ 14 / shire 24–28 — тривиально.
