# 0039. Допуск №1: цена стройки пути (Economist)

Дата: 2026-09-23. Роль: Economist. Первый допуск по ADR 0038 (очередь: цена
стройки → выход полей → фураж). Старые ADR не правятся.

## Контекст

Systems измерил (STATUS цикл 2, `test_cycle_road_river_roi`): мощение всего
соляного тракта покупает 0 для торга — `eta` упирается в пол `max(1, ceil)`,
каденция фиксирована. Хозяин решил: стройка в v0 принимается только по приказам
(дни в логе `send_march`); длину пути из обоснования стройки для торга выкинуть.
Замер Economist (шир, свежий `load_scenario`, seed 1729): коридор соли
`t_08_05 → t_01_01` — 15 входов, 19.0 дн; полным мощением — 12.0 дн (каждый вход
0.8), месяцы 1→1. Цена тракта: 15 × 30 = **450 трудодней + 60 брёвен**, минимум
3 мес/клетку при капе 12 (30/12 = 2.5 → 3), последовательно — **45 мес**.
Где врут руки: остаток рук книги корня после барщины — **1696 трудодней/мес**
(32 двора, пустых 0). Руки есть, а клетка всё равно стоит квартал: душит не цена
в днях, а кап 12 — ложное узкое место. Механика торга (путь, `eta`, каденция,
фураж, риск) и выход еды — вне допуска, не тронуты.

## Решение

Точечное удешевление стройки (только цена/темп, механика та же):

| Вид | Дни было → стало | `log` было → стало | Мес/клетку при капе |
|---|---|---|---|
| дорога | 30 → **20** | 4 → **3** | 3 → **1** |
| брод | 20 → **14** | 2 → **2** | 2 → **1** |
| мост | 40 → **28** | 6 → **4** | 4 → **2** |

Кап проекта: 12 → **20** дн/мес. Тракт соли: 450дн + 60 брёвен →
**300дн + 45 брёвен**, последовательно ~15–30 мес вместо 45. Поле по-прежнему
платит честно: дни уходят из остатка рук после барщины, материал — переводом
в `sink:waste` при `start_work`. Окупаемость для торга — по-прежнему 0 по
дизайну (вариант C, честная граница): дни 19→12, месяцы 1→1, каденция та же;
допуск покупает дни приказов (`send_march`), а не расписание обозов.

Зона: константы живут в `engine/roadworks.py` (зона Implementer). Правка внесена
Economist по прямому приказу хозяина (STATUS цикл 3: «Economist — допуски (цена
стройки первым ADR)») и только им; прецедентом для других зон не является.
Синхронизация чисел в `docs/04`/`docs/09` — очередь Scribe (как раньше).

## Альтернативы

- Резать только дни, держать кап 12 — отклонено: кап и был ложным горлом
  (клетка — 2 мес вместо 1, тракт — 30 мес вместо ~15).
- Поднимать только кап без резки дней — отклонено: дренаж поля растёт, а цена
  поколения (450 + 60) остаётся.
- Половинить всё — отклонено: грубо, без якоря; ×2/3 дней держит клетку
  соизмеримой с телегой (`craft_cart` 20дн).
- Трогать `eta`/каденцию/фураж ради «окупаемости» — отклонено: механика торга
  вне допуска (вариант B — отдельным ADR).
- Поднимать выход еды, чтобы поле «потянуло» стройку — отклонено: yield еды
  вне допуска.

  two 15/15.6/312 окно 14–18, shire 25/15.6/541 окно 24–28, дельта 0).

- И-1 цел (материал — перевод, дельта 0), И-2 цел (действия те же), И-3 цел
  (вести те же).
