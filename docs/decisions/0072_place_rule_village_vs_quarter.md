# 0072. Правило места: деревня против квартала (владелец)

Дата: 2026-09-24. По калибровке World (цикл 50): гекс 0,4 км, сельский гекс ≤ 5 дворов,
городской квартал — 20–40 семей, мастерские первых этажей, специализация кварталов.

## Контекст

Хозяин: в городе один гекс — квартал: ~10 домов по 2–4 семьи, первые этажи — мастерские,
кварталы специализированы (каменщики, бондари, оружейники, ювелиры/чеканка). World: текущий
`TILE_MAX_HOUSEHOLDS=5` — правило деревни; 20–40 дворов на гексе им не проходят, сущности
`House` нет (двор ≠ дом), рецепты привязаны к поселению, а не к кварталу.

## Решение

1. **Ёмкость гекса — по контексту места:** сельский гекс (деревня) ≤ 5 дворов
   (`TILE_MAX_HOUSEHOLDS` живёт); городской гекс (квартал) — 20–40 семей. Кап — правило
   места, не бонус: нарушение = отказ посадки, как в деревне.
2. **Сущности `House` в v1 нет.** «Дом» — это 2–4 двора-семьи на гексе квартала (визуально
   `dwelling`/многоэтажность уже есть в ADR 0065). Настоящее здание (этажи, стройка, тепло,
   престиж) — отдельный ADR позже.
3. **Специализация квартала — существующими рецептами и действиями:** мастерские работают
   через `Recipe.place=settlement` + `HouseholdAction.recipes` (ADR 0062: без новых юнитов и
   без поля «мастер»); квартал отличается набором рецептов своих дворов, а не новым полем.
4. **Город — `Settlement` с `works_tiles` на свои кварталы и пригородные тайлы**
   (пашни, луг, лес, мельница/мост) — обычная связка, без новой сущности.
5. **Порядок:** после сетки (0071) и временной шкалы; кап квартала — ADR с числами после
   замера плотности; сейчас — только правило и запрет обхода (20–40 дворов на сельском гексе
   запрещены).

## Альтернативы

- Считать все гексы деревнями (5 дворов) и «город» рисовать формой — отклонено: плотность
  города и мастерские кварталов — суть города, ярлык без закона (как было с `common`).
- Ввести `House` сразу — отклонено: новая сущность без стройки/этажей = ярлык.

## Последствия

- `settle_household` получает контекст места (деревня/квартал) — правило, не бонус.
- Производство квартала идёт существующими рецептами; новые товары — только через ADR + И-7.
- Каноны не сдвигаются: кап 5 для сельских гексов остаётся.

## Что запрещено

1. Обходить кап сельского гекса (20–40 дворов в деревне).
2. Вводить `House`/«мастерский статус» без ADR.
3. Считать квартал «большой деревней» в форме/законе.

## Проверка

```bash
bash sim/run_tests.sh
```

Критерий: сюит зелёный; тест (квартал 20–40 семей — разрешён контекстом, деревня >5 —
отказ); дельта 0; каноны в окнах.
