# 0042. Допуск №4: правило топ-апа волков (Economist, без фазы)

Дата: 2026-09-23. Роль: Economist. Четвёртый допуск по ADR 0038 (разведка World,
цикл 2: `wolves_den` — рычаг). Старые ADR не правятся. Зона строго своя:
каталог + тест каталога; фаза (`phase_hazard`) — следующим заходом Implementer.

## Контекст

Правило `wolves_den` объявлено, исполнителя `target==hazard` в тике нет.
Живые волки сценариев: `intensity` 0.6 / `population` 0.6 на лесной клетке
(`t_00_01` — лес, правилу есть где жить). Кража сейчас: `intensity × 0.5`;
давление пути: `population × голод` (`hazards/model.py`). Потолки обязаны держать,
иначе бесконечные волки.

## Решение

Контракт правила (только данные, `spawn_rules.yml`): `mode: topup` —
дотягивает СУЩЕСТВУЮЩИХ волков, новых сущностей `Hazard` не рождает (режима
spawn нет — иначе весть ниоткуда); бросок вероятностный через `rng_stream:
hazard` (детерминизм И-6 — за фазой); приросты `intensity_gain` 0.2 /
`population_gain` 1.0; потолки `intensity_cap` 1.0 / `population_cap` 6.0
(аналог `cap_per_tile`; выше живых 0.6 — правило не мёртво). Рост требует
`Report` (`report_required: true`) — рождение вести за Info при вшивке фазы,
иначе врёт И-3.

Конверт будущего эффекта (не поведение, а потолок): кража ≤ 1.0 × 0.5 = 0.5
зерна/мес со двора на клетке; давление пути — до ×10 нынешнего при сытой стае.
Без фазы правило молчит — зафиксировано тестом (12 мес шира: ни новых угроз,
ни дрейфа `population`/`intensity`).

## Альтернативы

- Режим spawn новых логов — отклонено: новая угроза без вести (И-3), новый
  продюсер `Pack`-типа (запрет цикла 2, как `sheriffs_ride`).
- Потолки выше/без потолков — отклонено: бесконечные волки.
- Вшить фазу этим ADR — отклонено: `phase_hazard` — чужая зона без exemption.
- Тронуть `band_camp` — отложено хозяином (кража 2.0 двигает голод, до замера окон).

## Последствия

Числа: влияния нет (молчание) — канон цикла 8 обязан стоять бит-в-бит,
включая хеши (hill 12/15.6/31, two 14/15.6/341, shire 26/15.6/547, дельта 0).
Гейты two ≥ 14 / shire 24–28 держатся тривиально; 13 = перебазировка.
Сюит +2 теста. Фаза — следующим заходом Implementer (плюс Info: весть);
ей же — `rng.hazard` и `Report` по этому контракту.

## Что запрещено следующим агентам

1. Рожать новые `Hazard` этим правилом (только topup).
2. Топ-ап без `Report` (И-3) и без `rng.hazard` (И-6).
3. Поднимать потолки без нового ADR с окнами.
4. Считать молчание «не работает» и дописывать фазу в каталоге.
