# 0046. Фаза рождения ватаги (Implementer, исполнитель `band_camp`)

Дата: 2026-09-23. Роль: Implementer. Исполнитель контракта ADR 0045 в
`phase_hazard` с наказами Critic (цикл 13): рождение только с вестью
(структурно), гейт per-tick. Весть — параллельно за Info; границу держу
чтением (вызов читателя + проверка ответа, текстов/канала здесь нет).

## Контекст

Ватаге некого дотягивать (её нигде нет): `mode: spawn`, условное появление
стоячей угрозы. Гейт `marsh` + 3 живых двора на клетке (замер 0045: не
стреляет нигде). Кража ватаги — 2.0 из `hazards.yml:band`, правилом не меняется.

## Решение

`_apply_hazard_spawns(world)` между топ-апом и кражей (новорождённые крадут
уже в этом месяце, как подросшие у волков):

- Перебор правил `target==hazard, mode==spawn` (сейчас только `band_camp`);
  числа — из `params`, хардкода нет.
- Гейт каждый тик, кэша нет: террейн клетки + живые дворы на ней (`left_at`
  учтён — уход mid-run сев закрывает); на клетке с активной угрозой того же
  вида не сеем (одна стоячая на клетку, рост сверх рождения — будущим решением).
- Бросок `base_prob` — потоком из `rng_stream` (`hazard`, И-6), по одному
  на прошедшую гейт клетку. Рождение `intensity_init`/`population_init`,
  рез потолками; `satiety` 0.4 (дефолт сценария); `spawn_rule_id` — честный
  id правила. Рождение материю не двигает: дельта 0.
- Наказ 1, структурно: выигрыш регистрирует сущность + метку
  `<rule_id>_birth_<hazard_id>` (штамп месяца, счётчик `<rule_id>_births` —
  заодно ответ на `counter_name_hardcoded` из ревью 0043; ключи волков
  заморожены живым читателем, не тронуты), затем зовёт
  `news.threats.report_pending_births(world)` и требует весть о клетке
  рождения с датой сегодня в ответе. Нет читателя или вести — откат
  (`_revert_birth` + счётчик назад): после фазы либо связка, либо ничего.
  Хук ищется `getattr` — до приземления читателя фаза молчит структурно.
  Флаг `report_required: false` (нет у текущих) шёл бы без читателя.
- Протокол сошёлся с приземлившимся читателем Info один в один (метка,
  штамп, ответ с `subject_id`/`event_date`, дедуп) — связка живая без правок
  с обеих сторон.
- Попутно: проводка кражи врала `reason="wolves"` всем видам — теперь
  `hazard.kind` (волкам то же слово, поведение то же, журнал честен).

## Альтернативы

- Рождение + весть из `phase_inform` — отклонено: рождение — симуляция
  (hazard-фаза), весть о нём — да, но атомарность «или всё, или ничего»
  держится только синхронным вызовом до конца фазы.
- Новое поле `Hazard` под метку — отклонено (поле только через ADR);
  бокового канала `world.stats` достаточно (прецедент 0043).
- Чтение мира читателем из фазы — нет: фаза зовёт читателя, отчёт строит он.

## Что запрещено следующим агентам

1. Рожать ватагу мимо связки (без вызова читателя и проверки ответа).
2. Кэшировать гейт; сеять вне топи / ниже `min_households` этим правилом.
3. Поднимать потолки/иниты/кражу без ADR с окнами.
4. Переименовывать ключи меток волков (живой читатель) и тексты Info.
