# 0038. Допуски производительности и видение баронства (владелец)

Дата: 2026-09-23. Решение хозяина-человека, вшивает владелец. Пересматривает ограничение
ADR 0033/0035/0036 («yield не поднимать»), старые ADR не правятся.

## Контекст

Шло от абсолютного запрета поднимать yield/выходы (ограничение Game Director, ADR 0033/0035/0036):
любой рост производительности читался как подгонка под окна. Хозяин-человек поставил иначе:
мы делаем игру-симулятор усадьбы, а не реальный симулятор мира — работать с допусками.
Где руки врут (стройка клетки = работа поколения, поле не кормит), производительность труда
и выход продукта можно поднимать. Концепт хозяина: большое баронство (пеший проход из угла
в угол ~2 дня), замок, деревни, растущие в городки 100–200 дворов, мастеровые, нативные деревни
племени, протоптанные тропы от ходьбы vs дорогие строеные дороги (престиж, караваны, уровень
города), уровни домов, таверны для путников, найм/невольники у свободных, военная служба 60–90
дней, в перспективе глобальная карта ~10 баронств.

## Решение

- **Допуски открыты.** Точечный подъём производительности труда / выхода продукта разрешён там,
  где врут руки (поле, стройка пути, тягло), — только через ADR с замером и окнами. Молчаливой
  перебазировки окон нет: канон перебазируется открыто, как смена 7.
- **Абсолютным остаётся И-1** (материя только переводом/рецептом/`external_in` по правилу,
  дельта 0), И-2 (право, не микроменеджмент), И-3 (знание только из `Report`).
- **Видение баронства — этапы, не закон v0.** Большая карта, нативные деревни, тропы vs дороги,
  уровни домов, таверны, служба 60–90 дней, глобальная карта — backlog этапов. Новый этап
  открывает только хозяин; новый слой механики без хозяина — отказ (бюджет сложности в силе).
- Очередь допусков: цена стройки пути (30/20/40 + log), выход полей, фураж по честным дням —
  каждым отдельным ADR с окнами, после приёмки Info+smelt.

## Альтернативы

- Держать абсолютный запрет — отклонено хозяином-человеком (душит руки, стройка = поколение).
- Поднимать без ADR и окон — отклонено (так рождается «сытый мир», врёт канон).
- Сразу проектировать большую карту кодом — отклонено (сначала допуски в v0, этапы — решением).

## Последствия

- Каждый допуск: ADR + замер + окна + зелёный сюит + дельта 0.
- Scribe-очередь и приёмка идут прежним порядком (Critic → Table → Scribe).
- Статус допусков — `STATUS.md`.

## Что запрещено следующим агентам

1. Поднимать выходы/цены/сроки без нового ADR с окнами.
2. Трогать И-1 под видом допуска (материя из ничего — брак всегда).
3. Перебазировать окна молча; вшивать этапы большой карты без решения хозяина.
4. Параллельные правки во время приёмки (freeze).

## Проверка

```bash
bash sim/run_tests.sh
```

Критерий: сюит зелёный; каждый вшитый допуск трассируется в свой ADR с окнами; дельта 0.
