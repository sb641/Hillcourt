# 0076. Гекс-сетка: аксиальные координаты и шесть соседей (Implementer)

Дата: 2026-09-24. Роль: Implementer. Исполнитель этапа ADR 0071 (топология, ни
одного правила). Старые ADR не правятся. Зона: `sim/`; правки чужих зон —
только импорт общего хелпера, по именному разрешению владельца.

## Контекст

Квадратная 4-соседская сетка: соседство было размазано по модулям
(`path.py`, `seat.py`, `tick.py`, `manor.py`, `economy/decisions.py`,
`economy/labor.py`, `economy/livestock.py`, `economy/exchange.py`,
`economy/thegn.py`, `legal/regimes.py`) — десять мест с локальными переборами
`(1,0),(-1,0),(0,1),(0,-1)`. Смена топологии бьёт по исходам физически:
миграция выбирает соседа из шести, `find_path` находит более дешёвые пути,
communal-доступ шире. Владелец разрешил открытый сдвиг, запретил подгонку
данных и запретил менять окна §1 этим ADR.

## Решение

### 1. Единый хелпер — `sim/src/hillcourt/engine/hexgrid.py`

Только топология, ни одного правила мира:
- `HEX_DIRECTIONS` — шесть единичных шагов аксиальной сетки `(q, r)`;
- `offset_to_axial`/`axial_to_offset` (odd-r раскладка), `tile_id_at`,
  `tile_id_of` — перевод координат карты ↔ аксиальных, без потерь;
- `hex_neighbors(tile)` — шесть соседей клетки; `neighbor_ids(world, tile)` —
  существующие клетки мира (граница = «нет клетки», не другая топология);
- `hex_distance`/`axial_distance` — шаги по гексу (замена манхэттена);
- `is_neighbor`/`axial_is_neighbor` — смежность.

### 2. Координаты: данные едут, id — нет

`Tile.coord` — аксиальная пара `(q, r)` (перевод в загрузчике). `tile.id`
остаётся `t_<col>_<row>`: YAML (`at:`, `works_tiles`, `rights`, `marks`,
`initial_hazards`), 23 тестовых модуля с прямыми id — не едут. `Settlement.coord`
хранит `[col, row]` карты, как раньше. Алгоритм Дейкстры и эвристики
`find_path` не тронуты — изменён только перебор соседей.

### 3. Соседство — только импорт хелпера

Все бывшие локальные переборы заменены на `engine/hexgrid.py`; своих
соседей в коде не осталось (пин `test_no_local_neighbour_math_in_world_modules`
грепает код мира). Тронутые чужие файлы — **только строка импорта плюс
замена перебора на вызов хелпера**, без правок формул, чисел, весов, профилей
и правил:

| Файл (зона) | Строки | Что |
|---|---|---|
| `economy/decisions.py` (Economist) | импорт + `adjacent_tiles` | соседи двора (6) |
| `economy/labor.py` (Economist) | импорт + `_adjacent_tiles` | соседи для рецептов |
| `economy/livestock.py` (Economist) | импорт + выпас | соседние пастбища |
| `economy/exchange.py` (Economist) | импорт + кластеры | соседние клетки |
| `economy/thegn.py` (Economist) | импорт + `_perceived_tiles` | слух тэна |
| `legal/regimes.py` (Legal) | импорт + `has_access_to_communal_tile` | соседний доступ |

Своя зона: `engine/hexgrid.py` (новый), `engine/path.py` (`neighbours`,
`_coord_index`, `known_tiles`), `engine/seat.py` (`_parse_tile_id` → аксиальные,
`compute_seat_tiles`, `manhattan` → гекс-шаги, `_adjacent`), `engine/tick.py`
(миграция, удалён `_grid_bounds`), `engine/manor.py` (`guard_ring`),
`scenario.py` (координаты клеток).

### 4. `state_hash` покрывает координаты

`Tile.coord` уже входил в хеш через `hazard_ids`/`regime`; сами координаты
добавлены в `state_hash` (строка `tile|...`), поэтому смена топологии видна в
хеше честно. Ключи сортировки — по id, как раньше (И-6).

### 5. Пины тестов, переведённые под гекс

- `test_march_path`: коридор обоза 6.0 → 5.0 дней (гекс короче), охотники 4.5
  — те же (пин не тронут).
- `test_caravan_module.test_paved_route_eats_less`: мощёный коридор 12 входов,
  фураж 0.48 (0.05×12×0.8 — мостовая цена обоза на входе).
- `test_caravan_trade.test_no_path_blocks_dispatch_and_keeps_delta`: кольцо воды
  вокруг цели — полное гекс-кольцо (шесть соседей через хелпер), иначе два
  лишних направления обходят блокаду.
- `test_communal_access.test_salt_regression_two_settlements_seed_99`: соль A1
  7.33 → 6.45 (регрессионный пин не окно §1; сдвиг честно объявлен ниже).

## Последствия

- Сюит **569 OK**.
- Перемер трёх канонов (сдвиг объявлен, окна §1 НЕ тронуты):

| Сценарий | Живые/соль/голод | Окно §1 | Хеш (было → стало) |
|---|---|---|---|
| hill 36/1729 | **13**/15.6/**28** | 8–15 ✓ | `cba2e0f47766` |
| two 60/42 | **17**/15.6/**384** | 14–18 ✓ | `387c241435c6` |
| shire 60/1729 | **24**/15.6/**548** | 24–28 ✓ | `efb6b9d38164` |

- Причина сдвига (честно): миграция выбирает соседа из шести (часть дворов
  уходит дальше и находит место → живых больше, уходов меньше), `find_path`
  дешевле (обозы ходят чаще/раньше → соль/рента/голод иные), communal-доступ
  шире (общие поля делятся шестью соседями).
- Дельта 0 во всех трёх; детерминизм: повтор того же seed — тот же хеш.
- Вода без переправы остаётся недостижимой (тест зелёный, кольцо по гексу).
- Подгонки стартовых данных не было: сценарии и стартовые склады не тронуты.

## Что запрещено следующим агентам

1. Возвращать локальные переборы соседей где-либо (только `engine/hexgrid.py`).
2. Менять окна §1 под этот сдвиг (этот ADR их не двигал; если нужно — новый ADR).
3. Подгонять стартовые данные сценариев под старые числа.
4. Менять формулы/числа/веса/профили «заодно с топологией».
