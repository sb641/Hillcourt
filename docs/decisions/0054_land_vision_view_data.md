# 0054. Земля баронства: вид и данные без механики

## Контекст

Цикл 20 STATUS: Economist считает сезонный выпас, картограф параллельно готовит
землю — вид и данные под пастбища, стоянки, шахты, пристани, дороги, рост
деревень, замок + скетч сценария. Видение — этапы, не закон v0 (цикл 3).
Ограничения захода: ни yield, ни storage, ни механика тика; каталоги
Economist/Legal и `client/` не тронуты; тик маркеров не пишет и не читает.

## Решение

В `sim/src/hillcourt/engine/tile_view.py` (вид, И-5) добавлены только вид
и данные; поведение тика, цифры добычи/выходов, кап 5, маршруты — без изменений:

- Каталог `FORMS` 17 → 26: `pier`, `trail`, `built_road`, `waystation`,
  `tavern_site`, `iron_mine`, `large_village`, `tribal_village`, `baron_castle`.
  `city`/`town` в каталог не входят (закон v0: городов нет, пин
  `test_catalog_has_no_city` цел).
- Маркеры `LAND_MARKS` (`trail`, `mooring`, `waystation`, `tavern`, `mine`,
  `tribal`, `castle`): разметка будущего сценария, читаются через `getattr`
  с дефолтом (полей на `Tile` нет — онтология не меняется). Без разметки вид
  прежний, кроме одной стадии роста: клетка 16 дворов (ясень) — `large_village`.
- Стадии роста видом: 1 двор — `single_homestead`, 2–9 — `village` (legacy-6
  цел), 10+ — `large_village` (`LARGE_VILLAGE_MIN_HOUSEHOLDS = 10`).
- Тропа vs строеная: `trail` — только маркер на пустой клетке; `built_road` —
  готовый `tile.road` на пустой клетке (дорога — завершённая работа, не краска).
  Жилая клетка показывает жильё, лагерь воза бьёт маркер стоянки.
- Данные: `PASTURE_FORAGE_CAPACITY` (пик сезона; `pasture` 2.0 = прирост
  `grow_hay`, остальное 0.0 — стоячего корма нет в каталоге) + чистая функция
  `pasture_forage_capacity`; `mine_sites` — учёт шахт (сегодня пусто).
  Стык с Economist — чтением: формулу сезонности ест его модель своим ADR.
- Тест `sim/tests/test_land_vision.py` — 16 пинов (каталог, маркеры, стадии,
  чистота данных, детерминизм).

## Скетч сценария баронства (видение, не YAML)

Замок барона (`castle`, стол видения) на холме у реки; рядом — пристань
(`mooring` + брод) и место под таверну; деревни 2–9 дворов вдоль строеной
дороги, большая деревня у развилки; деревня племени (`tribal`) за топью —
чужое жильё тем же счётом дворов; перевалочные стоянки (`waystation`) на
дневных переходах; шахта (`mine`) на топи у болотного железа; пастбища —
источник сезонного корма по `pasture_forage_capacity`; тропы (`trail`)
соединяют всё, что не удостоилось стройки. Имён собственных нет (И-8).

## Предложка механик (без кода, решать хозяину)

1. Самопрокладывание троп от ходьбы: счётчик проходов возов по клетке →
   маркер `trail` (порог + выцветание без ходьбы). Дешевле стройки, слабее
   дороги; риск — ползучая перекройка карты без приказа (И-2).
2. Рост деревень: стадии видом уже есть; механика — кап жилья/право рубки
   под стадию (Legal), без бонуса к урожаю.
3. Шахты: добыча остаётся рецептом; механика — истощение точки (потолок
   стоячего железа на клетку-шахту, аналог `cap_per_tile`).
4. Пристани/таверны: только вид и место сбора вестей (Info), без экономики.
Всё — отдельными ADR с замером окон; до решения тик маркеров не касается.

## Альтернативы

- Поля маркеров прямо на `Tile`: отвергнуто — меняет онтологию ради вида.
- `town`/`city` в FORMS сейчас: отвергнуто — врёт закону v0 и краснит пин.
- Ёмкость выпаса формулой здесь: отвергнуто — модель ест Economist, иначе
  два хозяина у одной цифры.

## Последствия

Дамп runner показывает новые формы (ясень — `large_village`); каноны стоят
(hill 12/31, two 14/341, shire 24/489, соль 15.6, дельта 0). Счётчик проходов,
рост, истощение — не заведены.

## Что запрещено следующим агентам

- Читать `pasture_forage_capacity`/`mine_sites` в тике без ADR хозяина.
- Давать формам бонусы (yield, storage, труд, рента): вид — не механика.
- Ставить маркеры в сценарии v0 и заводить `city`/`town` без решения хозяина.
- Писать маркеры тиком (проходы, рост) без ADR.
