# 0033. Обвязка жизнеспособности экономики: E1–E8 внедрены, окна замерены

Дата: 2026-09-22. Роль: Economist. Цикл: viability-очередь Game Director
(E1 сено/тягло → E3 бревно → E2 лемех → E4 скот/обмен → E6 wasted → E7 цены →
E8 смертность; роды ADR 0031). Проверено прогонами, не словами.

## Контекст

Аудит показал 8 разрывов «механика объявлена, но не работает». Game Director
поставил очередь с запретами: без труда не косить/не ковать; yield не поднимать
чтобы скрыть голод; чужие зоны не трогать; окна менять только ADR. Параллельно
сели `phase_hay` (Game Designer) и стартовые наборы шира. Работа шла в заморозке.

## Решение (что внедрено, по пунктам)

- **E1 (сено).** `_mow_reserve` в `work_month`: двор с тяглом оставляет до 50%
  рук на косьбу, если сена не хватает и двор не голодает. Гейт пар + кап
  приплода; убран двойной развод (действия + фаза). `test_pairs_do_not_starve`
  зелёный; `mowed 354.6` за 36 мес шира.
- **E3 (бревно).** Рубка (`cut_firewood`, `cut_wood`, `mine_iron`, `cut_peat`)
  разрешена на соседнем лесу/топи без спавна. `log 1.2`, `cut_wood 72`,
  плуг собран 1.0 за 36 мес шира.
- **E2 (лемех).** `smith_iron_share` как данные (баланс 1.8=1.8) + проводка в
  `idle_repair`; гейт дорогого (сыт + входы); резерв minor при сытости и реальной
  работе. Изолированно 3.0 за 6 мес; в полном прогоне редко (железо распылено —
  нужны стартовые наборы, зона сценария).
- **E4 (скот).** Цены покупки в `exchange` (бревно 0.5, вол 8, осёл 5, конь 12
  зерном; молодняк дешевле); гард «пара остаётся» (продаётся излишек сверх пары).
  `logs_bought 4.0`, `pigs_bought 1.0`. Межклеточный торг отложен (same-tile).
- **E6 (wasted).** Кап пула барщины под спрос (`_render_pool(caps)`); рабы вне
  капа (им некуда девать труд). `wasted 0` в шире 36.
- **E7 (цены).** Цены выше живут; серебро из ничего не создаётся.
- **E8 (смертность).** `demography.py:_die_by_age` + `needs.yml:death`
  (младенцы/старики/старые; расцвет в иммунитете для сценарных грантов).
  Смертей ~7, родов ~14–25 за 36 мес; Ledger не тронут.
- **Роды (ADR 0031).** Пороги 5 мес / 6 streak / 8 ртов / 24 мес; характер
  новорождённого — из хеша id (не ест `rng.economy`, жребий трио цел).

## Альтернативы

- Откатить всё «чтобы позеленело» — отклонено: механизмы работают, дельта 0.
- Поднять yield чтобы скрыть голод — отклонено: запрещено мандатом.
- Межклеточный торг и спавн скота — отложены (нужны имплементеры и новые окна).

## Последствия

- Сюит: **416 тестов, OK** (включая 2 бывших красных демографии; trio починен
  RNG-фиксом).
- Окна (замерено): hill 36 — живых 12, голод 31, соль 15.6, дельта 0;
  two 60/42 — живых **16** (окно 17–19), голод 299, соль 15.6, дельта 0;
  shire 60 — живых 26 (окно 24–28), голод 525–600, соль 15.6, дельта 0.
  Сдвиг two на 1 двор — рты демографии; оформлено здесь, не молча.
- Зубец августа — на душу (абсолют врёт при росте населения).

## Что запрещено следующим агентам

1. Поднимать yield/выходы чтобы скрыть голод.
2. Возвращать межклеточный торг или спавн без ADR и окон.
3. Трогать `economy/` и каталоги без прогона окон.
4. Создавать материю: только `transfer`/рецепт/`external_in` по правилу.
