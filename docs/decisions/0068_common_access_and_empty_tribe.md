# 0068. `common` даёт доступ; пустое племя честно (владелец)

Дата: 2026-09-24. По аудиту Systems (цикл 41): два расхождения закона и кода.

## Контекст

1. ADR 0060/Scribe-синк обещают: `Right.kind=common` — общий доступ. Код (Economist) исключил
   `common` из индивидуального держания (`own_tiles`/`_held_tile_ids`), но
   `has_access_to_communal_tile` (`legal/regimes.py`) читает только поселение/`works_tiles`/
   соседство и `common` **не даёт доступа**. То есть право объявлено, а механика половина:
   община не владеет — и не имеет доступа. Это хуже отсутствия права: игрок нарезает «право»,
   а оно ничего не меняет.
2. Племенный guard запрещает уход (`phase_migrate`), но голод не убивает: племенной двор может
   голодать бесконeчно (как `villein` — существующий закон). При смерти всех членов остаётся
   `Household` с нулём людей, форма продолжает называться `tribal_village` — визуальная ложь.

## Решение

1. **`common` = доступ.** `has_access_to_communal_tile` учитывает `Right.kind=common`
   (владелец клетки — держатель `common`): община получает доступ к своим клеткам, **не**
   становясь индивидуальным держателем (надел, `_plot_cap`, `own_tiles` — как было по 0060).
2. **Племенная пустота честна.** Смерть людей не создаёт новой механики (голод не убивает —
   старый закон), но: (а) двор без живых людей не считается живым для вида/знания/состава
   (`form`, `known_tiles`, подсчёты); (б) `Tribe` без живых дворов перестаёт платить оброк
   (нечего собирать) и не показывается как действующее племя игроку; (в) новый уход племенных
   дворов не открываем — мятеж/выход v2 по ADR 0066.
3. Зона `sim/src/hillcourt/legal/` закреплена за Legal в `AGENTS.md` (была вне карты).

## Альтернативы

- Убрать `common` из закона — отклонено: община реальна (ADR 0060/0062), право нужно.
- Дать `common` надел — отклонено (0060: община ≠ первый двор).
- Ввести смерть от голода для племени — отклонено: новая механика смерти вне бюджета;
  честная пустота вместо выдуманной казни.

## Последствия

- Код: Legal (`regimes.py`: доступ по `common`), Economist (оброк не берётся с пустых дворов),
  World (вид не называет пустое поселение племенем), Scribe (доки: доступ, пустота, ADR 0064 —
  «7 полей» → фактическое число).
- Проверка: тест «`common` даёт доступ, но не надел»; тест «двор без людей не входит в
  подсчёт/знание»; тест «пустое племя не платит».

## Что запрещено следующим агентам

1. `common` как индивидуальное держание.
2. Считать пустое поселение/племя живым в форме, знании или составе.
3. Вводить голод-смерть ради племени без отдельного ADR.
