# 0023. Местность и путь: terrain, профили хода, pathfinder, приказ send_march

## Контекст

Задача сессии «МЕСТНОСТЬ И ПУТЬ»: ход по стратегической клетке — не прямая и
не телепорт. Мир строит маршрут по стоимости клеток, у клетки есть terrain,
есть профили хода, приказ `send`/`march` к дальней клетке опирается на
существующий `Pack`, игрок не видит лучший путь по невидимой земле.
Ограничения сессии: не трогать службу тэна, живые обозы и канонные числа;
не вводить юниты, бой, новую экономику.

## Решение

1. `sim/src/hillcourt/engine/terrain.py` — закрытый список `TERRAINS` (9
   террейнов онтологии, не 40 биомов) и 4 профиля хода (строки, не классы):
   `caravan` (обоз: чаща 8.0, топь 6.0), `foot` (пешая свита),
   `hunters` (разведка: чаща 1.5), `mounted` (колонна: чаща 6.0, топь 8.0).
   Цена — дни входа в клетку; дорога дешевит вход; вода без брода/моста
   непроходима для всех.
2. `sim/src/hillcourt/engine/path.py` — `find_path`: Дейкстра по
   4-соседству, возвращает `(route, days)`, route — список клеток от origin
   включительно. Нет пути — `None`, а не прямая. Детерминизм: очередь
   `(дни, id)`. Вызывается только на приказ, не в тике (И-4, И-10).
   Туман: `known=None` — расчёт по миру (свои возницы); `known=<множество>` —
   приказ игрока, неизвестные клетки непроходимы (кроме цели). `known_tiles`
   и `remembered_road_tiles` читают только доставленные `Report` и `route`
   дошедших `Pack`; почта (`info/`, `news/`) не тронута.
3. `sim/src/hillcourt/engine/march.py` — `send_march`: цель — любая клетка
   с путём; `Pack kind="party"` (существующий разбор `resolve_packs`, риск —
   тот `Hazard`, что уже есть); в логе `route`, `months`, `profile`.
   Труд снимается как у `send_party` (20.0 за взрослого), материя не движется.
4. `Tile` получил `road`/`ford`/`bridge` (bool, default `False`);
   сценарии и starters не менялись. `runner.py` — только handler `send_march`.
5. Зонды `sim/tests/test_march_path.py` (15): обоз обошёл чащу (6.0 дн.
   против 11.0 прямой), охотники прошли чащей (4.5 дн.), вода без брода
   режет путь, брод пропускает, туман не даёт невидимый обход, лог приказа
   содержит маршрут/месяцы/профиль.

## Альтернативы

- Перевести живые обозы на pathfinder: отвергнуто — маршрут холм→ясень
  через топь закреплён тестом (`test_hazard_tile_scatters_share...`), смена
  маршрутов сдвинула бы риск, RNG-поток и канонные хеши. Манхэттен обозов
  оставлен как legacy; профиль `caravan` покрыт зондами pathfinder.
- Блокировать неизвестное vs штрафовать: выбрана блокировка — игрок не
  получает «лучший путь» по невидимой земле даже случайно.
