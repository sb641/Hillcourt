# 0055. Выпас с краем: корм из ёмкости пастбищ + дворы (Economist, шаг 2)

Дата: 2026-09-23. Роль: Economist. Шаг 2 правки хозяина (цикл 19): бесплатной
траве — отказ; летние 70 % — из ёмкости пастбищ. Вшивается пакетом с шагом 1
(ADR 0053). Старые ADR не правятся.

## Контекст

Шаг 1 считал летние 70 % из ничего. Край: стоячее сено пастбищ + кормовая
ёмкость клетки (`engine/tile_view.pasture_forage_capacity`: pasture 2.0/мес,
остальное 0 — только чтение, данные картографа не тронуты).

## Решение

Летний корм: 30 % сеном из своего стока + 70 % выпасом (`graze_for_herd`):
каждая клетка отдаёт не больше ёмкости в месяц (общий счёт месяца,
детерминированный порядок) и не больше стоячего сена — перевод в `sink:eaten`
(причина `graze`). Недобор выпаса — снова сеном из стока (скот у полного стога
не голодает), затем падёж прежней пропорцией. Зимой — полное сено, как раньше
(бит-идентично). Дворы — `engine/tick._feed_livestock` по именному разрешению
хозяина (только сезонная норма, прецедентом не является, раскрыто здесь);
амбары/гейты/косьба — шагом 1. Пастбища стойла: двор — где косит
(`hay_pastures`), амбар — клетки книги, склад — клетка + `works_tiles`.

## Альтернативы

- Недобор выпаса сразу в падёж — отклонено: скот у полного стога голодать
  не должен (поведенческая ложь).
- Отдельный месячный счётчик без штампа — отклонено: негде сбрасывать
  без хука; ключи со штампом самоописываемы.
- Нулевой коэффициент стойловым — отклонено хозяином (едят и летом).

## Последствия

Стенд `animals_starved` (шир 60 мес, 15 сидов): 4.0–9.0/год (было 10 при
круглогодичном сене, 0 при бесплатной траве) — честная середина: зима и разрывы
кусают, лето амнистирует. Выпас `hay_grazed` 61–91/год — кап работает, материя
из стоячей. Раннер: hill 12/15.6/31 бит-в-бит, two 14/15.6/341 бит-в-бит
(гейт ≥ 14), shire 24/15.6/489 (окно 24–28, кромка); соль 15.6, дельта 0.
Сюит 478 OK. Маржи трио (48/30/40): расход сена ниже — держат лучше;
стенд пар 6/25 (было 6/25 — без регресса, состав перетасован; взрыв нужды
прежний, см. 0052). И-1 цел (трава — стоячая материя, переводом).

## Что запрещено следующим агентам

1. Пасти сверх ёмкости/стоячего (трава из ничего — брак всегда).
2. Трогать данные картографа этим ADR (только чтение).
3. Расширять именное разрешение на другие функции движка.
