# 0203. Соседство клеток — одна правда, и она в `hexgrid`

## Назначение

Смежность клеток в гекс-мире считалась двумя способами, и один из них отвергал
четверть настоящих соседств. Закон: **смежность спрашивается одним способом, у
`engine/hexgrid.py`**, и больше нигде не выводится.

Наследует ADR 0071 (мир — гекс, аксиальные координаты), ADR 0155. Старые ADR не
редактируются.

## Контекст

`legal/actions.py::_adjacent` считала соседство **манхэттеном по координатам
карты**:

```python
def _adjacent(origin: str, destination: str) -> bool:
    ox, oy = int(origin.split("_")[1]), int(origin.split("_")[2])
    dx, dy = int(destination.split("_")[1]), int(destination.split("_")[2])
    return abs(ox - dx) + abs(oy - dy) == 1
```

Мир при этом гекс (ADR 0071), а `tile.id` хранит координаты карты (`col`/`row`),
которые раскладываются odd-r. Манхэттен по карте — **4 из 6** направлений, и
смешанная 4/6 топология запрещена прямым текстом
`engine/hexgrid.py`: «локальных переборов “своих” соседей в коде быть не должно».

Правильный расчёт был рядом: `engine/seat.py::_adjacent` через
`axial_is_neighbor`. То есть **на одних и тех же данных один приказ проходил, а
другой говорил «не соседняя»**.

### Замер (воспроизведён мной независимо, до правки)

По всем упорядоченным парам клеток сценария:

| сценарий | настоящих соседств | отвергнуто `legal._adjacent` | доля |
|---|---|---|---|
| `start_stand` | 46 | 12 | **26.1 %** |
| `v0_shire` | 516 | 160 | **31.0 %** |

Числа совпали с замером Стола плейтеста. Следствие, измеренное Столом:
`send_party` отказывает на гексе, который **является** соседом, а `send_sally` на
тот же гекс и на тот же маршрут принимается.

## Решение

### 1. Единственный вопрос о смежности — `hexgrid.tile_ids_are_neighbor`

```python
def tile_ids_are_neighbor(origin, destination) -> bool
```

Принимает клетки **по id** `t_<col>_<row>`, потому что так их спрашивают приказы
и вести: `send_party` держит на руках два id из записи сценария, а не объекты
`Tile`. Ответ — шесть аксиальных направлений, без манхэттена.

### 2. Формат id разбирает тоже `hexgrid`

`hexgrid.parse_tile_id` — единственное место, где строка `t_XX_YY` превращается в
координаты. Второго разбора быть не должно: «как выглядит id клетки» — одна
правда, как и смежность.

Несуществующая/чужая клетка соседом **не является** (`False`): иначе приказ
отправит людей в пустоту.

### 3. `engine/seat.py` спрашивает, а не решает

`_adjacent` в `seat.py` больше не содержит расчёта — он зовёт `hexgrid`. Смысл
правки не в том, что ошибка была в формуле, а в том, что **вопрос был задан
дважды**. Пока вопрос задают двое, один из двух ответов рано или поздно станет
неправильным.

### 4. Долг в `legal/actions.py` — заявка владельцу, не моя правка

`sim/src/hillcourt/legal/` принадлежит **Legal** (`AGENTS.md` §2), и в момент
сдачи файл правит другой агент. **Я не трогал `legal/actions.py`.**

Что нужно владельцу — ровно одна правка тела функции:

```python
# было
def _adjacent(origin: str, destination: str) -> bool:
    ox, oy = int(origin.split("_")[1]), int(origin.split("_")[2])
    dx, dy = int(destination.split("_")[1]), int(destination.split("_")[2])
    return abs(ox - dx) + abs(oy - dy) == 1

# станет (импорт рядом с прочими, тело — одна строка)
from ..engine.hexgrid import tile_ids_are_neighbor

def _adjacent(origin: str, destination: str) -> bool:
    return tile_ids_are_neighbor(origin, destination)
```

Зависимость `legal/` → `engine/hexgrid.py` уже существует в дереве: `legal/`
импортирует `..world`, `..ontology`, а `economy/*` и `engine/*` импортируют
`hexgrid`. Цикла импортов не возникнет: `hexgrid` не знает ни о `legal`, ни о
`world` — это чистая топология.

Пока запись не снята, долг **посчитан** в
`sim/tests/test_order_refusal_and_neighbour.py::KNOWN_LOCAL_TILE_ID_PARSERS`:
проверка зелёная не потому, что долга нет, а потому, что он записан и учтён.

## Альтернативы

- **Поправить `legal/actions.py` самому.** Отвергнуто: `AGENTS.md` §0.2 —
  чужая папка неприкосновенна, правка чужой зоны = откат, а не «улучшение».
  Тем более что файл правит другой агент прямо сейчас.
- **Скопировать `axial_is_neighbor` в `legal/actions.py` без `parse_tile_id`.**
  Отвергнуто: это всё ещё две правды, просто рядом. Следующая правка одной из них
  снова разойдётся с другой молча.
- **Оставить `legal._adjacent` и объявить 4/6 нормой.** Отвергнуто числами: 26 %
  и 31 % отвергнутых настоящих соседств — это не «другая норма», это ошибка,
  видимая игроку как «не соседняя клетка» на гексе, который сосед.
- **Запретить `send_party` на не-карточных направлениях.** Отвергнуто: тот же
  смысл, что у 4/6, только теперь официально — то есть игрок по-прежнему не может
  послать отряд на настоящего соседа.

## Последствия

- **`engine/seat.py` и `hexgrid` больше не могут разойтись** — вопрос один.
- **Четверть отвергнутых соседств в `send_party` перестанет отвергаться** после
  правки владельца `legal/`. До правки — не перестанет: это долг, а не исправление.
- **Новый модуль с собственным разбором id клетки роняет тест**, и это не даёт
  правде снова расползтись молча.
- **Симметрия и «не соседь самой себя» закреплены тестами-сторожами**, чтобы
  «починка» сравнением в одну сторону не прошла.

## Что запрещено следующим агентам

- **Не выводить смежность клеток вне `engine/hexgrid.py`.** Ни манхэттеном, ни
  «по списку соседей руками». Вопрос задаёт `tile_ids_are_neighbor`.
- **Не разбирать id клетки (`t_XX_YY`) вне `hexgrid.parse_tile_id`.**
- **Не добавлять новый модуль с собственным соседством, не сняв запись из
  `KNOWN_LOCAL_TILE_ID_PARSERS`.** Реестр долга — не помилка: он падает и на
  новом нарушителе, и на исчезновении записи.
- **Не считать, что `legal/actions.py` починен.** Он не тронут; заявка в §4.
