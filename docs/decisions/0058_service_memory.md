# 0058. Служебная память рядом с Ledger: barter_memory и remembered_road_tiles

Дата: 2026-09-24. Роль: Scribe. Микро-ADR по ревизии Systems (Д2/Д3, цикл 24):
`barter_memory` и `remembered_road_tiles` исполняются кодом и описаны в законе
(`docs/09`, `engine/path.py`), но отсутствовали в `docs/03`. Онтология пополняется
только через ADR — это он и есть. Старые ADR не правятся.

## Контекст

Ревизия Systems: обе структуры живут вне `docs/03` — `barter_memory` как словарь
мира (`world.py`), `remembered_road_tiles` как вычисление (`engine/path.py`).
При этом `docs/09` уже описывает память сделок, а приказы (`send_march`/
`send_river`) ходят по запомненным дорогам. Игрок ни то ни другое напрямую
не читает — знание только `Report` (И-3).

## Решение

Обе — служебная память рядом с `Ledger`, НЕ сущности мира:

- `World.barter_memory: dict[str, dict]` — память сделок вместо биржи. Ключ
  `origin->destination:good`; поля `carried` (сколько груза ушло со стоков
  origin), `delivered` (сколько доехало до стока назначения),
  `ratio = delivered/carried` (доля доехавшего груза, не цена),
  `lost` (сколько рассеялось у клетки). Цен нет вовсе. Пишет разгрузка
  (`resolve_caravans`); читают свои правила (последняя сделка с
  `ratio < min_ratio` — не везти впустую) и вести (`caravan`-отчёты строятся из
  `barter_memory`, а не из стоков). Нет памяти и нет отчёта — пробный рейс разрешён.
- `remembered_road_tiles(world) -> set[tile_id]` — вычисляется, не хранится:
  клетки с флагом `road` из маршрутов дошедших `Pack` (`status=arrived`).
  Приказ может вести по запомненной дороге и через неизвестное (возницы уже
  ходили этим путём) — задокументированный механизм пути, не чтение запасов
  (И-3). Террейны, стоки и опасности через него не читаются.

## Альтернативы

- Сущности мира с `id` — отклонено: у памяти нет бытия в мире, только учёт и маршрут.
- Молча держать в коде без закона — отклонено: ревизия Systems, И-9 (исполняемое
  покрывается законом).

## Последствия

- `docs/03` пополняется служебным пунктом рядом с `Ledger` (п.3 пачки Scribe).
- Поведение не меняется: только слова; канон и сюит не двигаются.

## Что запрещено следующим агентам

1. Читать `barter_memory` как цены/биржу; приписывать `ratio` меновое число.
2. Хранить `remembered_road_tiles` состоянием или читать через него стоки/опасности.
3. Давать игроку прямой доступ к служебной памяти мимо `Report` (И-3).
