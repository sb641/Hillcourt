# 0034. Снятие поля `produces_report` (C2)

## Контекст

Поле `produces_report: true` стоит в `design/catalogs/offices.yml:11,16`, парсится
загрузчиком (`sim/src/hillcourt/catalogs.py:292-301`, входит в `required`), но ни один
модуль симуляции его не читает. `messenger`-Report порождается безусловно, к должностям
не привязан. Решение Game Designer (C2) принято столом Game Director; альтернатива
«привязать messenger к должности» отклонена — это новая система должностей. Легитимные
производители `messenger` уже есть без поля: вылазки тэна шлют его через `send_party`
(ADR 0021).

## Решение

Поле `produces_report` упразднено: удалить из `design/catalogs/offices.yml` (обе записи)
и из загрузчика (`catalogs.py`: `known`/`required`, конструктор `Office`). Вести остаются:
обоз, молчание, события, диспетчерский `messenger` вылазок. Исполнитель — по решению
Владельца (загрузчик — Implementer; каталог должностей в таблице владельцев не значится).

## Альтернативы

- Привязать `messenger` к должности: отклонено — новая система должностей, которой нет в v0.
- Оставить поле мёртвым: отклонено — каталог врёт о мире, тест загрузчика требует несуществующее.

## Последствия

- C2 из `design/review/backlog_v0.md` закрыт. `test_catalog_rules` обновляется под отсутствие
  поля (без поля в `required`).
- Должности без депеш: дальний надзор — только обоз, молчание и события.

## Что запрещено следующим агентам

1. Возвращать поле без системы должностей, которая его читает.
2. Вводить систему должностей ради одного поля.
3. Читать мир напрямую ради вестей (И-3); LLM в тике (И-10).
