# 0037. Проводка выплавки крицы к действию (долг №1 закрыт)

Дата: 2026-09-23. Роль: Economist. Цикл: долг №1 STATUS (цикл 1).

## Контекст

Рецепт `smelt_iron_bloom` (`iron 1.2 + firewood 0.6 → iron_bloom 1.0`, потери
`iron 0.2 + firewood 0.6`, труд 10, баланс 1.8 = 1.8, `transform`) жил в каталоге
с ADR 0030, но к действию подключён не был: за 36 мес полного прогона 0 проводок,
железо распылено (`mine_iron` даёт 0.6 в никуда), комплекты тэна и лемех голодают.
ADR 0030 п.1 запрещал подключать выплавку без нового ADR с пересмотром окон.
Очередь `idle_repair` задана ADR 0035 E2:
`repair_axe → smelt_iron_bloom → smith_iron_share → smith_kit`.

## Решение

Нового кода не потребовалось: проводка уже была в законе (рецепты `idle_repair`
в `actions_household.yml`, гейт дорогого `EXPENSIVE_FOOD_MONTHS = 2.0` и кап
1 партии/мес в `economy/labor.py`). Засвидетельствовано зондами причинности:
сытый двор (`food_months` 11.4) с входами выплавляет крицу действием
(`work_month`, причина `smelt_iron_bloom`, дельта 0); голодный (`food_months` 0)
— 0 проводок, железо 2.4 цело. Появления крицы нет: ни одно правило
`spawn_rules.yml` не производит `iron_bloom`. Порядок E2 держится и в каталоге,
и в порядке срабатывания (`_recipe_order`: еда первой, далее по `id` —
`repair_axe < smelt_iron_bloom < smith_iron_share < smith_kit`; `smith_axe`
между — параллельная ветвь топора, не цепи крицы).
Закрыто тестом `TestSmeltWiring` (`sim/tests/test_bloom_and_hay.py`):
порядок очереди, выплавка сытым действием, запрет голодному, дельта 0,
отсутствие `external_in` по крице. Stale `docs/09` (§5, §10) снят.

## Альтернативы

- Поднять приоритет выплавки над `craft_*` в очереди — отклонено: сдвигает
  бюджет мелкого дела и канон без приказа Owner.
- Отдельный бюджет/труд на кузню вне остатка — отклонено: труд из воздуха,
  нарушает «руки — главная валюта».
- Смягчить гейт (голодный тоже куёт) — отклонено: голодный кормит семью, не горн.
- Спавн крицы правилом — отклонено: магия, И-1/И-7.

## Последствия

- Поведение тика не менялось (только тест + 2 строки `docs/09` + этот ADR):
  канон смены 7 обязан стоять — hill 12/15.6/32, two 15/15.6/312 (окно 14–18),
  shire 25/15.6/541 (окно 24–28), дельта 0 везде.
- В полных прогонах выплавка останется редкой, пока железо распылено:
  стартовые наборы железа — зона сценария (Implementer), не этого ADR.
- `TOOL_YIELD_FACTORS`, `seasons.yml`, выходы еды — не тронуты.

## Что запрещено следующим агентам

1. Поднимать yield/выходы, чтобы выплавка «выглядела живой».
2. Давать кузне отдельный труд вне остатка месяца.
3. Снимать гейт сытости без нового ADR с окнами.
4. Вводить появление крицы (`external_in` без правила).
5. Класть железо в стартовые наборы без зонда окон (зона сценария).
