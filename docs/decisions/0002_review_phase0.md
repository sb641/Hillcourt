**Роль:** Critic (независимый).

**Дата:** Y1 (фаза 0).
**Проверенный базис:** `bash sim/run_tests.sh` — 15/15 зелёных (0.648s); прогон 36 месяцев, дельта материи `0.0`, `external_out = 0.0`.

## Краткое резюме (executive summary)

Фаза 0 в основном **честная по агрегатной сумме материи**: за 36 месяцев `Ledger.delta ≈ 7e-12`, отрицательных остатков нет, «дворы едят и платят/не платят ренту», «двор уходит и не возвращается», «игрок видит датированное известие» — эти четыре пункта `docs/02_scope_v0.md` **подтверждены эмпирически**.

Однако найдены **два блокера**, которые делают доказательство сохранения материи несостоятельным как гарантию, даже если конкретный прогон случаенно чист:

1. **BLOCKER. `Ledger.emit` создаёт материю.** Выдача из «пула обработки» списывает общий остаток пула, но зачисляет получателю **заказанное** количество любого товара, не сверяя, что именно этот товар реально был в пуле. Сумма материи сохраняется, а состав — нет: `grain 3.0` в пуле → на выходе `salt 3.0`. Балансовый тест каталога проверяет только равенство сумм и **не ловит подмену товара**. Это прямой обход И-1 в коде `Ledger` и незакрытая дыра в `test_catalog_rules`.
2. **BLOCKER. Всеведение игрока реализовано.** `PlayerView` отсутствует, но `phase_inform` кладёт в `Report.facts` **точное истинное** значение (`grain` холма и дворов, `salt` деревни), а не рассказ. Игрок из лога восстанавливает истину клеток/дворов в обход `Report`. `distorted` всегда `False`; искажение «сдвиг числа» не реализовано; `stale` отсутствует. Это нарушение И-3 и обещаний `docs/05`.

Далее: скрытый tech-tree отсутствует; дюпа товара в текущем прогоне не найдено (нет save/load — фиксируется как отсутствующее); `spawn_rules` для `hazard/pack/ruin` не исполняются (deferred, частично допустимо фазой 0, но заявлено в каталоге как рабочее).

## Находки

### F-1. BLOCKER — «Вечный двигатель» в `Ledger.emit`: подмена товара при сохранении суммы

**(b) Где:** `sim/src/hillcourt/ledger.py:100-135`, вызывается из `sim/src/hillcourt/economy/labor.py:47` и `:54`.
**(d) Инвариант:** И-1 («материя не берётся из ничего», любой объект — перевод; см. `docs/00:10-13`); косвенно И-7 (объект обязан иметь место/рецепт).

**Суть.** `emit` проверяет только `src.total() >= amount`, затем дренирует пул в произвольном (sorted) порядке товаров, но зачисляет получателю `dst.add(good, amount)` по запрошенному `good` — **без проверки, что в пуле был именно `good`**. Фактически это бартер mass-в-mass без сверки состава. Если вызывающий рецепт указывает `outputs`, которого не было во `inputs`/`draws_standing`, новый товар возникает «из ничего».

`apply_recipe` (`labor.py:12-59`) перекладывает ответственность на каталог: единственная защита — `abs(processing.total()) < 1e-6` (`labor.py:56`). Но это проверка **суммы**, не состава. `test_catalog_rules.test_recipes` (`sim/tests/test_catalog_rules.py:36-52`) тоже сравнивает только `sum(...) == sum(...)`.

**(c) Воспроизведение (минимальное, без правки репо):**

```bash
PYTHONPATH=sim/src python3 - <<'PY'
from hillcourt.ledger import Ledger
from hillcourt.ontology import Stock, SimDate
led = Ledger(); d = SimDate(1,1)
pool = Stock("sink:processing","sink","processing",{})
out  = Stock("household:h","household","h",{})
led.external_in(pool, "peat", 3.0, "seed", None, d)
print("pool:", pool.amounts)           # {'peat': 3.0}
led.emit(pool, out, "gold", 3.0, "recipe", d)
print("after:", pool.amounts, out.amounts)  # {} {'gold': 3.0}
PY
```

Реальный путь рецепта: `Recipe(draws_standing={'grain':5.5}, outputs={'salt':5.0}, loss={'grain':0.5})` проходит и балансовый тест каталога (`5.5 == 5.5`), и `apply_recipe` (processing обнулится), создавая 5.0 соли из 5.5 зерна — «золото из ничего».

**(e) Минимальный контрпример:** пул с `peat: 3.0`; `emit(pool, dst, "gold", 3.0)` → в мире `peat` исчез, `gold` появился. Сумма та же, состав подменён. Материя не создана «в сумме», но создан **объект, которого не было**, что и есть нарушение И-1 в терминах онтологии (перевод между контейнерами одного и того же вещества).

**Почему тесты зелёные:** текущий каталог сбалансирован по составу, поэтому дыра не проявляется на `v0_hill_and_salt.yml`. Это ложная гарантия: любой будущий рецепт с опечаткой в id товара создаст вечный двигатель молча.

### F-2. BLOCKER — Всеведение игрока: `Report.facts` содержит точную истину

**(b) Где:** `sim/src/hillcourt/engine/tick.py:322-410` (`phase_inform`); приёмные точки `:336-341`, `:354-364`, `:370-380`, `:387-397`. Плюс `sim/src/hillcourt/news/propagation.py:11-41` (`distorted` всегда `False`).
**(d) Инвариант:** И-3 (`docs/00:20-23`); нарушены обещания `docs/05_information.md:28-36` (искажение, `stale`, «нет ссылки на истину»).

**Суть.**
- `hill`-отчёт: `content=f"Холм: зерна во дворе {court_grain:.1f}"`, `facts={"grain": round(court_grain,3)}` — точное значение истинного стока двора игрока (`tick.py:330-341`). Формально это «свой двор», но `docs/05:35` обещает агрегат из `Report`, а не прямой доступ; здесь доступ к истине — напрямую (`world.get_stock(...)`), минуя какую-либо модель наблюдения.
- `neighbor`: `facts={"grain_approx": round(grain,1)}` — истинное зерно конкретного двора (`tick.py:350-364`). Проверено: число в отчёте = истинному остатку двора на `event_date`, лишь округлённому до 0.1. Игрок по одному отчёту узнаёт истину любого соседа.
- `caravan`: `facts={"salt_approx": ...}` из истинного стока `salt_village` (`tick.py:382-397`).
- `distorted=False` у всех отчётов (проверено: `any(r.distorted) == False`), хотя `docs/05:16-22` обещает «мелкое/среднее/сильное» искажение, а `make_report` принимает `distorted`, но `phase_inform` никогда его не выставляет.
- `stale` (просрочка, `docs/05:23-26`) не существует ни как поле, ни как логика.

Вывод показывает `{'grain_approx': <истина>}` / `{'grain': <истина>}` без искажения.

**(e) Минимальный контрпример:** после `run_month` №2 `neighbor`-отчёт по `fs_03` содержит `grain_approx` ровно равное истинному зерну этого двора (округлённому), т.е. игрок читает истину клетки/двора через `Report`, а не рассказ о ней.

Классифицирую как **broken now**, а не `deferred`: `docs/02_scope_v0.md:32` прямо требует «игрок в логе видит известие с датой, **а не истину клетки**» — то есть доказательство фазы уже сейчас обязано исключать истину, а оно её не исключает.

## Что проверено и чисто (аудит)

- **Баланс рецептов по составу в текущем каталоге:** `harvest_grain 5.5=5.5`, `cut_firewood 4.2=4.2`, `cut_peat 3.15=3.15`, `boil_salt 9.0=9.0`. Состав совпадает (peat/brine → salt, loss = остаток). **Чисто.**
