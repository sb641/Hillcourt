# 0036. Приёмка зелёная: viability E1–E8, offices без депеш, окна §1

Дата: 2026-09-22. Стол Game Owner: приёмка дерева после viability-очереди (ADR
0033/0035), снятия `produces_report` (ADR 0034) и реабилитации `phase_hay`.
Проверено столом лично (сюит + три канона), не со слов агентов.

## Контекст

Дерево проходило через красную фазу (смена 6: 3 демографических падения + флэп
подписей обмена от параллельных правок). Автор довёл: резерв косьбы, гейты
дорогого/приплода, покупка, кап пула, смертность + иммунитет расцвета, характер
из хеша. Параллельно снято мёртвое поле должностей. Freeze держался с момента
поручения (mtime тихи с 19:54).

## Решение (что принято и вшито)

- Сюит **416 OK** (проверено столом; прежде 411 с 3 красными — все закрыты автором).
- Окна §1 держатся: hill 12/15.6/32, two 15/15.6/312 (14–18 ✓), shire 25/15.6/541
  (24–28 ✓); дельта 0 везде. Дрейф живых (18→15, 28→25) — рты минус uplift/gates,
  зафиксирован открыто. Узкое 17–19 two — за автором демографии (не молча).
- `produces_report` упразднено везде кроме истории (yml/загрузчик/`Office`/тест);
  вести — обоз, молчание, события (C2 из backlog закрыт).
- Yield не поднят числами (`TOOL_YIELD_FACTORS`, seasons целы — сверено): эффект
  только достижимостью (плуг/тягло) — заработанный, не нарисованный (ограничение GD).
- Закон: `docs/03` (`Office`), `docs/07` (должность без депеш), `docs/09` (E1–E8),
  `docs/02` (люди/лемех/косьба), `ACCEPTANCE` (смена 7 ЗЕЛЁНАЯ + §7), `CHANGELOG`.

## Альтернативы

- Откатить viability «чтобы было как было» — отклонено: механизмы работают,
  мандат FULL-GO требует доведения, не отката.
- Перебазировать окна молча — отклонено: И-9 (смена 7 фиксирует дрейф поименно).
- Чинить red-зону правками стола в код — отклонено: зона не моя.

## Последствия

- Приёмка флага стола закрыта: сюита зелёная + окна 60 мес при стабильном дереве.
- Долги (не блокеры): проводка `smelt_iron_bloom` (владелец, с окнами); TBD в ADR
  0035 — финализировать владельцу измеренными числами (окна выше — база);
  stale-комменты (`needs.yml:41`, `v0_shire.yml:167-170`, `river.py:252`);
  потоки RNG на стойло; межклеточный торг; выпас/приоритет косьбы (двойной вызов —
  удаление предложено владельцу `livestock.py`).
