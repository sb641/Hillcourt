# 0050. Одна косьба: добор и резерв удалены (Economist)

Дата: 2026-09-23. Роль: Economist. Закрывает долг двойной косьбы (цикл E,
предложение ADR 0032/0036). Старые ADR не правятся. Зона строго своя:
`economy/livestock.py`, `economy/labor.py`, тесты своего модуля.

## Контекст

Косьба шла дважды: `phase_hay` (до поля) + добор в `livestock_month` (конец
`phase_consume`), плюс `_mow_reserve` жал поле в `work_month` под поздний добор.

## Решение

Удаление (обоснование гейтами не прошло — замер): стенд шир 60 мес, V0 vs V1
(без добора и резерва) — накосили одинаково 209.7, `starved` пар одинаково,
дельта 0. Добор за 60 мес накосил 0: пастбища к концу месяца пусты (ранняя фаза
их уже выбрала), а резерв жал поле под добор, который не косит, — чистый убыток
рук. Единственная косьба — `phase_hay`; `_mow_reserve` удалена (полю все руки).
Поле E1 (ранняя косьба) цело; убран только поздний довесок.

## Альтернативы

- Оставить оба с гейтами — отклонено замером: добор косит 0, резерв вредит.
- Убрать только добор, держать резерв — отклонено: резерв без добора = руки
  лежат без дела (поле их не видит, косить некому).

## Последствия

Замер V1 (стенд): alive 26, hunger 545, соль 15.6, `starved` пар как в V0,
накос 209.7 — равенство там, где добор молчал; поле получило резервные руки.

Раннер (сдвиг открыт): hill 12/15.6/31 бит-в-бит, two 14/15.6/341 бит-в-бит
(гейт держится), shire 26/15.6/545 (было 539, +6 — окно 24–28 держится);
соль 15.6 и дельта 0 везде. Сюит 455 OK, пары `starved` = 0.
И-1 цел (рецепт/перевод), И-2 цел (решения те же), И-3 цел.
Синхронизация `docs/04`/`docs/09` (две косьбы) и docstring `phase_hay` в
`engine/tick.py` — очередь Scribe/Implementer (чужие зоны, не тронуты).

## Что запрещено следующим агентам

1. Возвращать поздний добор/резерв без замера против этого.
2. Косьба — только ранняя фаза; труда из воздуха нет.
3. Трогать кап пастбищ этим ADR.
