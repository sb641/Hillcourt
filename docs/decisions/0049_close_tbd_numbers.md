# 0049. TBD 0035 закрыт: измеренные числа допусков (владелец)

Дата: 2026-09-23. Закрывает TBD из ADR 0035 («финализировать владельцу измеренными
числами»). Старший ADR не правится.

## Контекст

TBD требовал зафиксировать измеренные числа viability-очереди E1–E8. С тех пор вшиты:
проводка smelt (0037), цена стройки (0039), сентябрьский пик (0040), фураж по дням (0041).
Канон ехал циклами 8 → 15.

## Решение (измеренные числа — база цикла 15)

- Сюит: **455 OK**. Дельта 0 везде. Соль 15.6 везде.
- hill 36/1729: живых **12**, голод **31**.
- two 60/42: живых **14** (окно §1 14–18, узкое 17–19 снято ADR 0048), голод **341**.
- shire 60/1729: живых **25** (окно 24–28), голод **539**.
- Рента шира 132.6; соль Pack-цепочкой (`load/unload > 0`, `external_in 0`, телепорт 0).
- Волки живые (топ-ап с капами + весть, ADR 0042/0043/0044); ватага вшита связкой
  (ADR 0045/0046, гейт молчит в каноне).

## Альтернативы

- Оставить TBD висеть — отклонено (долг с цикла 1, числа есть).
- Перебазировать окна под текущие — отклонено (окна §1 держат, кромка 14 — честный исход).

## Последствия

- TBD 0035 закрыт. База приёмки — числа выше; меняет их новый ADR, не прогон.
- Остаток долгов: двойная косьба, RNG на стойло, межклеточный торг,
  `counter_name_hardcoded`, TBD нет.

## Что запрещено следующим агентам

1. Читать TBD 0035 как открытый (закрыт здесь).
2. Подгонять окна под прогон вместо нового ADR.
