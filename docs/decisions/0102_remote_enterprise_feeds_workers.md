# 0102. Удалённое хозяйство кормит своих работников (Orchestrator)

Дата: 2026-09-25. Роль: Orchestrator (владелец решения). Продолжение ADR 0092. Повод: хозяин —
«солеварня, как и любое удалённое хозяйство — каменоломня, солеварня, прочее, — должна обеспечивать
харчами работников».

## Назначение

Предприятие вдали от баронского двора — солеварня, каменоломня, лесопилка — **само кормит своих
работников**. Пока оно этого не делает, работник уходит искать еду, и промысел мёртв.

## Контекст

На баронстве солевары уходят в `hire_out`, потому что с предприятия им дают соль натурально, а
еды нет. Исторически солеварни, рудники и каменоломни держали **собственное продовольствие**:
хлеб, пиво, сыр, соль — и нанимали работников «с харчем» (`die Kost`/`Kost`), либо крестьяне
отрабатывали подённую повинность с содержанием. Без содержания нанимать некого.

## Правила

1. **Солеварня, каменоломня и всякое удалённое предприятие имеют свой продовольственный
   запас** (склад поселения — уже существующий `Settlement.stores`) и **кормят работников** из
   него: харч зерном/продовольствием по потребности двора плюс соляная/товарная доля (ADR 0092,
   0101). Это **расход предприятия**, а не милость: он виден в числах.
2. **Обеспечение работников — условие жизни промысла, а не опция:** если продовольствия нет,
   работник уходит по закону (`free_landless` без найма уходит) — это честный отказ
   предприятия, и игрок видит причину (нет корма/дохода у промысла).
3. **Солевары — наёмные безземельные, `free_landless`:** у них нет наделов, и их единственная
   связь с поселением — **найм в предприятие**. Найм даёт: харч + доля (соль/товар) + часть
   деньгами (ADR 0101); без найма они уходят. Это и есть содержание закона о безземельных.
4. **Дворы с наделами (виллан, коттер) предприятием не кормятся:** у них своё хозяйство
   (ADR 0097); если двор в солеварне имеет надел, он платит за место работы сам, а не ест из
   амбара предприятия.
5. **Предприятие не кормит «всех подряд»:** только тех, кого реально наняло и кому платит; запас
   тратится по `monthly_food_need` и за недоплату честно считается долг (уже есть
   `saltworks_short`).
6. **Продовольствие предприятия — из обоза и местных запасов:** оно пополняется тем же обозом, что
   везёт соль (двусторонняя торговля), а не появляется из воздуха (И-1).

## Проверка

```bash
PYTHONPATH=sim/src python3 -m unittest sim.tests.test_remote_enterprise -v
```

Критерий: предприятие с полным складом кормит работников и держит их; без корма — уходят с
видимой причиной; двор с наделом в солеварне не ест из амбара предприятия; `delta = 0`.

## Что запрещено следующим агентам

1. Солеваре без продовольствия при найме.
2. Найму «в обход» найма (двор работает на предприятии, но не считается нанятым и не ест).
3. Кормлению из чужого амбара (у кого нет найма).

## Альтернативы

- **Найм без содержания.** Отклонено: работник уйдёт искать еду — ровно то, что происходит.
- **Солевары как вилланы с наделами.** Отклонено: солеварня — не пашня; `holder` без надела в
  старых мирах — канон, а в новой карте солеварь — наёмный безземельный.

## Последствия

- Промысел оживает, когда у него есть корм; игрок получает решение «кормить промысел или он
  умрёт» — это и есть содержание солеварни.
- Числа старых миров не трогаются (солеварни там — `holder`), правка только новой карты.
