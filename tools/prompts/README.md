# Роли агентов

Карточки ролей для вызова субагентов. Владелец папки — Orchestrator.
Формат вызова: `роль → цель → входные файлы → критерий приёмки → запрещённая зона`.

Роль — это контракт, не персона. Один агент может вызвать другую роль сменой карточки.
Постоянные правила (кто где пишет, DoD, запреты) — в `AGENTS.md`.

| Карточка | Роль |
|---|---|
| `economist.md` | товары, рецепты, хранение, рента, появление материи |
| `legal.md` | права, повинности, недоимка, переход держания |
| `info.md` | рождение/задержка/искажение/смерть известия |
| `critic.md` | адверсариальная проверка |
| `implementer.md` | код, тесты, runner |
| `scribe.md` | документы под критику |

## Проверка

У каждой карточки есть блок «Запрещённая зона», совпадающий с таблицей владельцев в
`AGENTS.md` (раздел 2). Критерий: при вызове роли в промпте переданы все пять пунктов формата.
